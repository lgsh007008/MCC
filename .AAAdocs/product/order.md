## R-订单-001：成品销售单录入与方量计算

调研依据：`.战略与经营/01第一阶段规划/业务调研-成品销售单.md`（飞书「成品销售单」「成品销售明细」两表）。

### 单据结构

**成品销售单（主表，一对多明细）**

| 字段 | 口径 |
| --- | --- |
| 销售单编号 | 系统自动生成（年月+当月流水，如 202611-0001），只读、永不复用 |
| 销售日期 | 手填，默认当天 |
| 客户名称 | 文本，手填；customer 域建成后回迁为外键（待补，见文末注记） |
| 合计方量 | = 明细方量之和，只读 |
| 小计金额 | = 明细单行金额之和，只读 |
| 其他金额 | 手填（运费等） |
| 合计金额 | = 小计金额 + 其他金额，只读 |
| 备注 | 手填 |

**成品销售明细（明细表）**

| 字段 | 口径 |
| --- | --- |
| 销售明细编码 | 系统自动生成 = 主单编号+行序（如 202611-0001-01），只读 |
| 产品类型 | 枚举，本版两值：板材 / 其他 |
| 长度 / 宽度 / 厚度（cm） | 3 位小数；板材必填，其他不适用 |
| 根数 | 整数；板材必填，其他不适用 |
| 方量（m³） | 4 位小数，自动 = 厚度/100 × 宽度/100 × 长度/100 × 根数；板材 |
| 单价（元/m³） | 2 位小数，手填，随单走（不同客户、不同订单单价可不同）；板材 |
| 小计金额 | 板材自动 = 方量 × 单价（2 位小数）；其他手填该行金额 |
| 其他金额 | 手填兜底（两类通用，默认 0） |
| 备注 | 手填 |

明细不单独存销售日期与客户：界面显示随主表（原飞书表明细冗余存客户，系统化后去掉）。

### 计算口径

- 方量 = 厚度cm/100 × 宽度cm/100 × 长度cm/100 × 根数，逐行舍入保留 4 位（四舍五入）
- 板材行小计金额 = 方量 × 单价，逐行舍入保留 2 位
- 单行金额 = 小计金额 + 其他金额
- 主表小计金额 = Σ单行金额；主表合计金额 = 小计金额 + 主表其他金额
- 主表合计方量 = Σ明细方量

### 产品类型与计算

- **板材**：按方量计费（规格自动算方量，小计 = 方量 × 单价），行上仍可手填其他金额兜底
- **其他**：非方量产品，规格区与单价不适用，行金额（小计金额）手填，行上仍可手填其他金额兜底
- 后续新类型随新需求追加枚举值并补计算规则（【待补】）

### 编号规则

- 主单编号自动生成：年月+当月流水（如 202611-0001），只读、永不复用
- 明细编码 = 主单编号+行序（两位行号），生成后不回改
- 删除单据 = 软删除，编号不回收

### 页面设计

按 `product/平台布局.md` 页面模式规范（列表页 / 表单页 / 详情页）执行，本页特有口径如下：

- **列表页**：筛选字段 = 销售日期区间、客户名称；列 = 编号、销售日期、客户、合计方量、小计金额、其他金额、合计金额、备注；可排序列 = 销售日期、合计方量、合计金额；行操作 = 查看 / 编辑 / 删除；批量删除可用；合计行汇总 = 合计方量、小计金额、其他金额、合计金额（标签在编号列），范围按筛选全量
- **表单页**：主表字段见上方单据结构；明细行按产品类型切换字段显隐、实时计算方量与金额（明细上限与区域高度沿用表单页模式默认值）；行操作 = 复制 / 删除（图标按钮）；复制为整行深拷贝（含根数）追加到明细末尾，达行数上限不可复制；面包屑标识：新建页 =「新建」，编辑页 =「单号 / 编辑」（单号可点击回详情）；校验：销售日期与客户名称必填、至少一行明细；板材行长宽厚 > 0、根数 ≥ 1、单价 ≥ 0；金额非负
- **详情页**：标题 = 销售单编号（客户名称括注）；面包屑标识 = 销售单编号；信息条 = 销售日期、合计方量、小计金额、其他金额、合计金额、备注；主体 = 明细表（列：编码、类型、厚度 / 宽度 / 长度（cm，分列展示）、根数、方量、单价、小计金额、其他金额、备注）

### 待补与归属注记

- **收款记录、欠款余额**：本轮不建。调研发现（欠款常态、新销售累加/回款核减、收款仅现结关联）归 finance 域建成后另立需求
- **客户外键**：customer 域建成后，客户名称回迁为外键关联客户档案
- **其他产品类型的计算规则**：随新需求追加
