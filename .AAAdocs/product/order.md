## R-订单-001：成品销售单录入与方量计算

调研依据：`.战略与经营/01第一阶段规划/业务调研-成品销售单.md`（飞书「成品销售单」「成品销售明细」两表）。

### 单据结构

**成品销售单（主表，一对多明细）**

| 字段 | 口径 |
| --- | --- |
| 销售单编号 | 系统自动生成（年月+当月流水，如 202611-0001），只读、永不复用 |
| 销售日期 | 手填，默认当天 |
| 客户 | 选择客户档案（外键关联 `product/customer.md` R-客户-001）；仅「启用」客户可选；同时保存下单时的客户名称快照（客户改名不回改历史单据） |
| 合计方量 | = 明细方量之和，只读 |
| 小计金额 | = 明细单行金额之和，只读 |
| 其他金额 | 手填（运费等） |
| 合计金额 | = 小计金额 + 其他金额，只读 |
| 备注 | 手填 |

**成品销售明细（明细表）**

| 字段 | 口径 |
| --- | --- |
| 销售明细编码 | 系统自动生成 = 主单编号+行序（如 202611-0001-01），只读 |
| 产品类型 | 当前**仅「方木」**，服务端固定写入；新建/编辑表单不提供选择，详情只读展示；后续产品类型随产品管理需求扩展 |
| 厚度 / 宽度 / 长度（mm） | **整数毫米**，必填且 > 0 |
| 根数 | 正整数，必填 |
| 方量（m³） | 4 位小数，自动 = 厚度 × 宽度 × 长度 × 根数 ÷ 10⁹；**所有行都计算并落库**（工资依据） |
| 计价方式 | 枚举：按方量（默认）/ 按根数；行级选择，同一单允许混用 |
| 单价 | 2 位小数；按方量 = 元/m³，按根数 = 元/根 |
| 小计金额 | 按方量 = 方量 × 单价；按根数 = 根数 × 单价；均 2 位小数、只读 |
| 其他金额 | 手填，默认 0（行级人工调整项） |
| 备注 | 手填；用于产品描述（如「方木 20×100×3000」） |

明细不单独存销售日期与客户：界面显示随主表（原飞书表明细冗余存客户，系统化后去掉）。

### 计算口径

- 方量 = 厚度mm × 宽度mm × 长度mm × 根数 ÷ 10⁹，逐行四舍五入保留 4 位
- 按方量行小计 = 方量 × 单价，逐行四舍五入保留 2 位
- 按根数行小计 = 根数 × 单价，保留 2 位
- 单行金额 = 小计金额 + 其他金额
- 主表小计金额 = Σ单行金额；主表合计金额 = 小计金额 + 主表其他金额
- 主表合计方量 = Σ明细方量（每行必有方量）

### 产品类型与计价方式

- **产品类型**：当前只有「方木」一种，由服务端固定写入，用户不可选择；接口创建/更新**不接收** `productType`，详情与列表响应返回
- **计价方式与产品类型解耦**：计算不再由产品类型决定，而由行级计价方式决定
  - **按方量（默认）**：单价元/m³，行小计 = 方量 × 单价
  - **按根数（少数情况）**：单价元/根，行小计 = 根数 × 单价
  - 两种方式下**方量都照常计算并落库**，供工资统计使用；同一张单允许混用
- **其他金额**保留为行级人工调整，不再承担「无尺寸产品兜底」
- 后续新增产品类型（如板条）随产品管理需求追加枚举与计算规则（【待补】）

### 编号规则

- 主单编号自动生成：年月+当月流水（如 202611-0001），只读、永不复用
- 明细编码 = 主单编号+行序（两位行号），生成后不回改
- 删除单据 = 软删除，编号不回收

### 页面设计

按 `product/平台布局.md` 页面模式规范（列表页 / 表单页 / 详情页）执行，本页特有口径如下：

- **列表页**：筛选字段 = 销售日期区间、客户（下拉选择客户档案；含停用客户，便于查历史单）；列 = 编号、销售日期、客户（显示下单时的名称快照）、合计方量、小计金额、其他金额、合计金额、备注；可排序列 = 销售日期、合计方量、合计金额；行操作 = 查看 / 编辑 / 删除；批量删除可用；合计行汇总 = 合计方量、小计金额、其他金额、合计金额（标签在编号列），范围按筛选全量
- **表单页**：主表字段见上方单据结构；客户为下拉选择（只列启用客户；编辑历史单且客户已停用时仍显示并保留该客户，允许其余字段照常保存）；明细行不显示产品类型，改由行级「计价方式」（按方量 / 按根数，默认按方量）驱动计算——长宽厚为整数毫米、根数为正整数、单价按计价方式标注单位（元/m³ 或 元/根），小计金额两种方式下均只读；实时计算方量与金额（明细上限与区域高度沿用表单页模式默认值）；行操作 = 复制 / 删除（图标按钮）；复制为整行深拷贝（含根数、计价方式）追加到明细末尾，达行数上限不可复制；面包屑标识：新建页 =「新建」，编辑页 =「单号 / 编辑」（单号可点击回详情）；校验：销售日期与客户必填、至少一行明细；长宽厚为 > 0 的整数、根数 ≥ 1、单价 ≥ 0；金额非负
- **详情页**：标题 = 销售单编号（客户名称快照括注）；面包屑标识 = 销售单编号；信息条 = 销售日期、客户编号（客户档案已删除时标注「已删除」）、产品类型（方木）、合计方量、小计金额、其他金额、合计金额、备注；主体 = 明细表（列：编码、厚度 / 宽度 / 长度（mm，分列展示）、根数、方量、单价（按行标注元/m³ 或 元/根）、小计金额、其他金额、备注），不单列计价方式

### 待补与归属注记

- **收款记录、欠款余额**：本轮不建。调研发现（欠款常态、新销售累加/回款核减、收款仅现结关联）归 finance 域建成后另立需求
- **产品类型扩展**：板条等新产品随产品管理需求追加枚举值、表单选择与计算规则
- **工资取数**：payroll 域未来按明细方量计算工资，本域保证每一行都有尺寸与方量（含按根数计价的行）
- **客户需求单与履约对比**：**有意不承载**。客户需求以口头 / 微信提出且随时可改，最终以拉货前确认的成品销售单为唯一出货事实源；不做「需求 vs 出货」对比，不建生产批次模型；退货与补货属逆向流程，暂不考虑。未来若需立需求单（如要求正式报价/合同、跟踪欠交量、排产依赖系统数据），按新需求编号另立
