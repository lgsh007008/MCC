# 生产与库存领域（production）

> 定位：生产与库存领域的**需求**（What）。实现设计见 `design/生产与库存.md`。
> 编号规则：`R-生产-NNN`
> 范围界定：生产批次（轻量成本对象）、原木领用单与方木产出单（两个独立单据）、原木与方木库存、库存估值、期初库存、库存盘点、每单材料毛利计算。产品类型本期仍固定「方木」；不做产品管理、排产、工序、计件、设备、毛料 / 净料双库存。销售单详情展示材料毛利归 order 域（`product/order.md` R-订单-003），本域只定义计算口径与查询接口。
> 调研依据：`.战略与经营/01第一阶段规划/业务调研-生产与库存.md`（2026-11-14）。该调研中「方木规格为文本、需统一乘号」的前提已被订单域结构化尺寸取代，本期按整数毫米长 / 宽 / 高聚合，不再引入文本规格。

## 口径声明

- **数量与金额分层**：先保证原木吨数、方木方数准确，再按成本池计算库存估值与每单材料毛利；本期不引入人工、费用分摊。
- **净尺寸口径**：销售单填净尺寸，方木产出单也录净尺寸；加工损耗不单独建模，自动体现在「每方成本」里。
- **轻量批次**：原木全厂一个成本池；方木按生产批次分别核算，批次之间不混摊；销售按批次日期先进先出扣层，成本可追溯到批次。
- **实时聚合**：库存数量、库存金额、批次平均成本实时计算，不落库存快照；每单材料毛利按下单快照，见 R-生产-004。
- **负数可见**：允许负库存并醒目提示；成本不完整时标「估算」，不伪造精确值。
- **管理视图**：库存估值与每单材料毛利是经营参考，不进入 finance 的收支汇总，不作为对外财务报表。
- **物料模型简化（本期定位）**：原木视作原材料、方木视作成品，净尺寸规格即隐式 SKU；原木一个移动加权平均成本池，方木按批次一个成本池。本期不建产品主数据、BOM、工序、仓库；「完整物料主数据 + 工单」作为升级路径记录在 `design/生产与库存.md`，本期不推进。

## R-生产-001：原木领用

### 单据结构

**原木领用单（单头，无明细）**

| 字段 | 口径 |
| --- | --- |
| 领用单编号 | 系统生成 `MI` + 5 位流水（如 `MI-00001`），只读、永不复用 |
| 领用日期 | 手填，默认当天 |
| 领用吨数 | 必填，大于 0，最多 3 位小数；表示本次从原木库存领出的实物吨数 |
| 备注 | 手填，≤500 字，可空 |
| 创建时间 | 系统写入，只读 |

- 原木领用与方木产出是**两个时间点的两个动作**，分属两张单据、两个列表，不在一张单上同时录入。
- 领用只记吨数，不录规格、批次或毛尺寸；一张领用单不关联采购单。
- 领用不因原木库存不足被阻断：保存时提示，库存页标负库存。

### 计算口径

- 领用成本 = 领用吨数 × 领用日当时原木平均成本，由系统计算，不在领用单上手填。
- 领用成本先从原木成本池转入**本批次待结转成本**；待结转不计入库存总值，领用单本身不保存金额。
- 方木产出时，把本批次待结转成本全额转入本批次方木成本池；批次平均成本在领用后到产出前保持不变，库存总值在领用后短暂减少、产出后恢复。
- **同一批次内约定一批原木对应一张产出单（可多行规格）**；同一批次分多张产出单时，第一张会拿走全部待结转成本，后续产出成本为 0。产出日期不得早于本批次领用日期，否则成本不会结转到该产出单。
- **逐单归属只用于追溯、不参与成本计算**：每个批次独立一个待结转池；为让页面能看出「哪笔领用还没产出」，按事件顺序（业务日期 → 创建时间 → 编号）以「最早未结转的先结转」推导每笔领用的已结转 / 待结转金额与每张产出单的本次结转金额。推导结果之和恒等于该批次待结转总额。

### 编号规则

- 编号 `MI` + 连字符 + 5 位全局流水（如 `MI-00001`），不含日期；只读、永不复用。
- 删除为软删除，编号不回收。
- 格式口径见 `1-产品文档.md`「五、全局编号规范」；本域登记前缀 `MI`。

### 页面设计

按 `product/平台布局.md` 页面模式规范执行，本页特有口径如下：

- **列表页（PC，`/admin/production/issues`）**：筛选 = 领用日期区间（标准筛选条：日期起 / 至、查询、重置）+ 结转状态（全部 / 待结转 / 已结转）+ 生产批次；操作区 = 新建 + 选中后批量删除；列 = 编号、生产批次、领用日期、领用吨数、结转状态、备注、创建时间；领用日期倒序；首列多选（本页全选，翻页 / 改筛选即清空）；合计行汇总领用吨数；行操作 = 查看 / 编辑 / 删除，删除与批量删除均二次确认，文案说明编号不回收。
- **表单页（PC，`/admin/production/issues/new`、`/[id]/edit`）**：标题 =「新建原木领用」/「编辑原木领用 + 编号」；字段 = 领用日期、生产批次（必选进行中批次）、领用吨数、备注；校验：日期必填、批次必选、吨数 > 0 且最多 3 位小数；保存成功跳详情；已关闭批次的单据不能编辑或删除。
- **详情页（PC，`/admin/production/issues/[id]`）**：标题 = 编号；信息条 = 领用日期、生产批次（链接到批次详情）、领用吨数、结转状态、已结转金额、待结转金额、创建时间、备注；有结转时显示「结转来源」——按推导列出产出单编号（纯文本展示，不跳转）；操作 = 编辑 / 返回列表；删除只在列表行操作。
- **移动页（`/m/production/issues`）**：入口 = `/m/production`「原木领用」；列表 = 卡片按领用日期倒序（顶行 = 领用日期 + 结转状态徽标，主行 = 编号 + 领用吨数，次行 = 批次编号）+「加载更多」+ 底部固定「新建原木领用」；不设筛选组与批量操作；表单 = 单列（日期、批次、吨数、备注）；详情只读，信息条含批次、结转状态 / 已结转 / 待结转，底栏 = 编辑（主色）/ 返回列表（描边），`production:manage` 时内容区提供「删除原木领用单」（整行描边红字，二次确认）。
- **权限**：查看 `production:view`；新建 / 编辑 / 删除 `production:manage`。

### 边界

- 不做生产排班、工序、机台、班组、计件、设备、仓库与批次。
- 领用只记吨数，不录毛尺寸或毛方数。
- 不从采购单指定原木批次。
- 领用单不改变采购单、销售单数据。

## R-生产-002：库存与估值

### 口径

**库存数量**

- 原木库存（吨）= 期初原木吨数 + 启用后采购送货吨数 − 启用后原木领用吨数 + 盘点调整吨数（不含期初）。
- 方木库存（m³）= 期初方木方数 + 启用后方木产出净方数 − 启用后销售出库净方数 + 盘点调整方数（不含期初）。
- 采购送货吨数取采购单的**送货吨数**；数量口径不使用结算吨数。
- 销售出库取未软删销售单明细的方量；方木产出入库取未软删产出单明细的方量。
- 所有库存按**净尺寸规格**聚合：产品类型（方木）+ 长度 + 宽度 + 高度；方木同时按生产批次分别核算，原木为全厂一个池。

**成本池与估值**

- 原木成本池：全厂一个；期初原木金额 + 采购合计金额 − 原木领用成本 + 盘点调整金额（不含期初）。
- 待结转成本：按生产批次分别记录；原木领用时增加本批次待结转，方木产出或批次关闭时全额转出；盘点不调整待结转。
- 方木成本池：按生产批次分别记录；期初方木金额进入「期初库存批次」，各批次 = 本批次产出结转的待结转成本 − 本批次销售出库材料成本 + 分摊到本批次的盘点调整金额。
- 原木平均成本 = 原木成本池金额 ÷ 原木库存吨数，全厂共用。
- 批次方木平均成本 = 本批次方木金额 ÷ 本批次方木方数；不同批次可以不同，批次之间不混摊。
- 库存总值 = 原木成本池金额 + Σ各批次方木成本池金额；**不含待结转成本**，因此领用后总值短暂减少、产出后恢复。
- 成本守恒：原木成本池 + Σ批次待结转 + Σ批次方木成本池，在销售与盘点之外保持不变。
- 采购合计金额含单价 × 结算吨数 + 其他金额；用「采购合计金额 ÷ 送货吨数」把折价与运费摊入每吨实物成本。
- 销售出库按批次日期先进先出扣层：先卖老批次，卖完再卖新批次，各层按该批次平均成本计价；全厂加权平均仅作参考展示。
- 金额展示保留 2 位；方量 4 位；吨数与平均成本展示保留 3 位；内部成本按高精度计算，不因展示精度影响成本与毛利。
- 事件排序：期初固定最前；其余按业务日期升序，同日期按创建时间与编号升序；批次关闭事件按关闭时间排序；产出必须排在其对应领用之后，否则成本不会结转。

**期初库存**

- 上线日录入一次期初：原木吨数与金额、方木各净尺寸规格的方数与金额。
- 期初金额进入成本池；期初数量计入库存。
- 库存计算从期初日期开始；期初日期之前的采购、领用、产出、销售单据不参与库存与成本池，只作业务记录，避免历史产出缺失导致失真。
- 期初只能在上线初始化时录入；已发生库存变动后不可改期初，只能走盘点调整。
- 期初录入属于库存调整单的一类，编号 `IC`。

**负库存与成本不完整**

- 允许库存数量为负，页面醒目提示。
- 销售单不因方木库存不足被阻断：保存时提示「当前规格库存不足，保存后库存将为负」，库存页标负库存；不做库存预占与锁定。
- 原木领用单不因原木库存不足被阻断：保存时提示，库存页标负库存。
- 当库存数量 ≤ 0 或无有效成本时，平均成本沿用最近一次有效值；无有效值时按 0 展示并标「成本待补」。
- 负库存期间计算的库存值标「估算」；每单材料毛利按快照口径处理，见 R-生产-004。

### 数据来源

- 采购送货吨数与采购金额：对 purchase 域的 `purchase_orders` 做只读聚合（本域只读，不写采购表；与 finance 应收应付只读聚合同一口径）。
- 销售出库方量：对 order 域的 `sale_orders` / `sale_order_items` 做只读聚合（本域只读，不写销售表）。
- 本域拥有原木领用单、方木产出单、库存调整与成本池计算。

### 页面设计

按 `product/平台布局.md`「聚合页」模式执行，本页特有口径如下：

- **库存页（PC，`/admin/production/inventory`）**：无日期筛选；顶部操作区右侧放「期初库存」描边按钮（始终显示：未设置期初进录入页，已有期初进只读详情页），不设盘点按钮（盘点入口只走「生产 → 库存盘点」菜单）；操作区显示库存总值；待结转成本 > 0 时同时显示「待结转 X 元（不计入库存总值）」；下方为页内 Tab：
  - `原木库存`（默认）：原木库存（吨）、原木库存值两张指标卡 + 原木库存表（列 = 库存对象、数量（吨）、平均成本（元/吨）、库存值（元）、状态；单行「原木」）。
  - `方木库存`：方木库存（m³）、方木库存值两张指标卡 + 方木库存表（列 = 产品类型、长度、宽度、高度、库存方数、平均成本（元/m³）、库存值（元）、状态；按规格逐行）+ 批次库存表（列 = 批次、批次日期、状态、方数、金额、平均成本、待结转；按批次逐行，负库存缺口单独一行）。
  - Tab 写入 URL，`?tab=timber`；默认 `原木库存`，刷新 / 深链保留，非法值回默认。
  - 当前 Tab 内负库存项数 > 0 时显示警示条；数量为负或成本待补的行用警示色并显示「估算 / 成本待补」标签。
- **期初库存（PC，`/admin/production/inventory/opening`）**：
  - 未设置期初：表单页；字段 = 期初日期、原木吨数与金额、方木各规格方数与金额；金额可填单位成本或总额，二选一；保存前二次确认；保存后生成 `IC` 调整单。
  - 已有期初：只读详情页；展示 IC 编号、期初日期、操作人、备注、原木吨数与金额、方木各规格方数与金额、合计金额；不提供编辑 / 删除，修正只能走库存盘点。
- **移动页（`/m/production/inventory`）**：单列；顶部整行分段按钮「原木库存 / 方木库存」，状态写入 `?tab=timber`；每个 Tab = 数量 / 金额两张卡 + 明细卡列表（原木一张卡 / 方木按规格逐卡）；库存总值卡在待结转成本 > 0 时附注「待结转 X 元（不计入库存总值）」；负库存卡片用警示色并标「估算 / 成本待补」；底部固定「期初库存」主按钮（未设置进录入页，已有期初进只读详情），库存页不放盘点按钮；不出现表格与横向滚动。
- **库存口径说明弹窗（弹窗说明，只读）**：入口在库存页说明句右侧（PC）与库存总值卡标题右侧（移动），移动端复用同一弹窗；三组——① **怎么算**：原木库存（吨）= 期初 + 采购送货 − 原木领用 ± 盘点，方木库存（m³）= 期初 + 方木产出 − 销售出库 ± 盘点，库存总值 = 原木库存值 + Σ批次方木库存值（不含待结转）；② **成本怎么走**：采购进货原木池加吨数、加金额（取采购单合计，含运费与折价）；原木领用原木池减吨数、减成本，成本记入所选批次待结转、不计入库存总值，产出时全额转入本批次方木池；方木产出加方数并把本批次待结转转入；销售出库按批次先进先出扣方数并扣各批次材料成本；盘点差异按当前成本计价并按批次先进先出分摊，待结转不参与盘点；批次平均成本 = 批次金额 ÷ 批次方数，批次之间不混摊；③ **为什么这样、与收支什么关系**：估值只算材料成本，不含人工、电费、房租；负库存或无有效成本时沿用最近有效成本估算并标「估算 / 成本待补」；采购支出已在收支汇总的经营收支按采购单计入一次，领用 / 产出 / 盘点不再进入收支，避免重复计算；收尾一句：本页回答「仓里还有多少、值多少钱」，赚没赚看收支汇总；底部只有「关闭」。
- **权限**：查看 `inventory:view`；期初设置与盘点 `inventory:manage`。

### 边界

- 不做安全库存、库存预警、库龄、跌价准备。
- 不做毛料库存、在制品库存、仓库货位；批次仅作成本对象，不做批次质检 / 保质期 / 序列号。
- 采购单 / 销售单的编辑与删除会实时回算库存与成本池；期初日期之前的单据变动不影响库存；本期不做删除守卫，负库存由库存页提示。
- 库存估值不进入 finance 收支汇总；如未来要进入财务报表，按新需求与 ADR 另立。
- 本期不做库存估值的历史快照；页面展示当前值。

## R-生产-003：库存盘点

### 口径

- 一张盘点单只盘一类库存：要么只盘原木，要么只盘方木；生成一张 `IC` 调整单，编号 `IC` + 5 位流水。
- 盘点日期默认当天；不得早于期初日期、不得晚于今天。账面数量按保存时当前系统库存，不做历史日期的复盘。
- 每个盘点行记录：库存对象（原木 / 方木）、方木规格（净尺寸长 / 宽 / 高）、账面数量、实盘数量、差异、单位成本、差异金额、原因、备注。
- 账面数量取当前系统库存，只读；实盘数量手填，**默认为空**，留空的行不参与本次盘点。
- 差异 = 实盘 − 账面；差异为正即盘盈、为负即盘亏，由系统按正负判断，用户不选盘盈 / 盘亏。
- 差异为 0 的行与实盘留空的行都不生成调整明细；整单没有任何已填行时拒绝保存。
- 差异按当前成本计价；方木差异按批次日期先进先出分摊到各批次；成本不完整时按最近有效平均成本估算并标记。
- 待结转成本不参与盘点；盘点差异只调整原木成本池或方木成本池。
- 原因 = 计量误差 / 漏记 / 损耗 / 其他，**选填、不设默认值**；留空按「其他」落库。
- 差异金额进入「盘点损益」，不摊到每单材料毛利。
- 盘点不冻结业务、不做审批、不做多人会签；确认差异后保存即生成调整单并生效，库存立即变化。

- 期初库存也通过库存调整单录入，类型 = 期初；普通盘点类型 = 盘点。
- 盘点记录展示操作人（创建时快照）、盘点日期、盘点类型、编码与差异汇总；不提供编辑 / 删除，修正只能再次盘点。

## R-生产-004：每单材料毛利计算

### 口径

- 订单确认收入：现结单取实收金额，赊销单取合计金额（与 finance 收入口径一致）。
- 订单材料成本 = 销售单保存时的材料成本快照：按批次日期先进先出扣层，各层方量 × 该批次平均成本后合计；快照同时记录加权平均单价与各层批次明细。
- 方木批次成本在产出或批次关闭时更新；销售按当时各批次余额扣层，批次之间不混摊。
- 销售单首次保存时，由 order 调用本域批次感知的成本计算方法，写入销售单成本快照与来源批次层；之后采购、生产、盘点变化不改历史订单。
- 无有效成本时快照为 0，成本状态 =「成本待补」；不提供独立重算入口，编辑保存本单时尝试补录一次，成功后锁定。
- 编辑销售单：已锁定订单按原快照单价 × 新方量重算材料成本；方量变化时清空原来源批次层，避免层明细与方量不一致；「成本待补」订单可尝试补录并写入新的批次层。
- 订单材料毛利 = 订单确认收入 − 订单材料成本（快照）。
- 材料毛利率 = 订单材料毛利 ÷ 订单确认收入；收入为 0 时不计算，显示「—」。
- 页面标注「下单时成本快照，未含人工与费用」。
- 销售单保存前若当前没有有效批次方木成本，页面二次确认提示「先录方木产出、产出日期填在销售日期之前」，并说明保存后材料成本记「成本待补」且库存估值受影响；确认后仍允许保存（不阻断开单）。编辑单仅在成本待补时提示。
- 库存估值仍是当前值，会随成本变化；历史订单材料毛利是快照值，不随成本变化；两者不要求相加等于某个数。
- 本口径不进入 finance 收支汇总，不替代月度经营净额。
- **材料毛利口径说明弹窗（弹窗说明，只读）**：入口在销售单详情材料毛利卡标题右侧（PC 与移动同位置），移动端复用同一弹窗；三组——① **怎么算**：确认收入现结取实收、赊销取单据合计；材料成本 = 下单时按批次日期先进先出扣层，各层成本合计，单据显示加权平均单价；材料毛利 = 确认收入 − 材料成本，毛利率 = 材料毛利 ÷ 确认收入（收入为 0 显示「—」）；② **为什么是快照**：成本在下单时锁定，之后采购、领用、产出、盘点如何变化都不改历史单；毛利卡可展开查看本单扣到的批次层与各层金额，超过 3 层时在口径弹窗的「本次成本来源」里看全部；没有有效成本时记「成本待补」、毛利留空，补录产出后编辑保存本单即可补上成本；③ **不含什么**：不含人工、电费、房租、折旧与销售费用，不等于收支汇总的净额，也不是整厂利润率，只用于看单张单子的料本毛利；销售出库按批次先进先出扣减，但不影响本单已锁定的成本；收尾一句：本页回答「这一单的料本赚了多少」，整体经营看收支汇总；底部只有「关闭」。

### 接口与权限

- 本域提供批次感知的成本计算公开方法：order 在销售单新建与编辑保存时调用，按批次日期先进先出返回金额、加权单价与来源批次层；销售单快照字段归 order 域。
- 订单详情通过 order 的只读材料毛利接口展示快照，要求 `profit:view`；无权限返回 403，前端不显示材料毛利卡。
- 不提供独立的成本重算接口；「成本待补」订单的补录只发生在编辑保存销售单时（同一次调用本域计算方法），补录成功后锁定。
- 计算由服务端统一提供，前端只展示、不重算。

### 边界

- 不含人工、电费、运费、房租、折旧等费用分摊。
- 不做订单级费用录入、不做订单利润审批、不做利润排行。
- 不改变销售单金额、结算方式、应收口径。
- 打印单据不展示材料毛利。
- 已锁定快照不因后续成本变化自动重算；只有「成本待补」订单在编辑保存时尝试补录一次。

## R-生产-005：方木产出

### 单据结构

**方木产出单（单头 + 多行产出）**

| 字段 | 口径 |
| --- | --- |
| 产出单编号 | 系统生成 `PR` + 5 位流水（如 `PR-00001`），只读、永不复用 |
| 产出日期 | 手填，默认当天 |
| 生产批次 | 必选，进行中的生产批次；产出成本只结本批次 |
| 产出总方数 | 只读 = 明细方量之和，4 位小数 |
| 备注 | 手填，≤500 字，可空 |
| 创建时间 | 系统写入，只读 |

**产出明细**

| 字段 | 口径 |
| --- | --- |
| 行序 | 系统生成，用于明细标识；行删除后不重排 |
| 长度 / 宽度 / 高度（mm） | **净尺寸**，整数毫米，必填且 > 0；按业务习惯依次录入长、宽、高 |
| 根数 | 正整数，必填 |
| 方量（m³） | 4 位小数，自动 = 长度 × 宽度 × 高度 × 根数 ÷ 10⁹ |
| 备注 | 可选；如规格描述 |

- 一张产出单至少一行产出；允许同一张单产出多个规格。
- 产出单必须选择一个生产批次；方木入库成本来自本批次待结转成本的结转，批次之间不混摊。
- 产出单是**方木库存入库的依据**，但不是排产单、工序单或计件单。

### 计算口径

- 方量 = 长度mm × 宽度mm × 高度mm × 根数 ÷ 10⁹，逐行四舍五入保留 4 位。
- 产出总方数 = Σ明细方量。
- 产出单本身不保存金额；产出时把本批次待结转成本全额转入本批次方木成本池。
- 产出不因原木库存不足被阻断；负库存由库存页提示。
- 同一批领用请在一张产出单内录完（可多行规格）；同一批次分多张产出单时第一张拿走全部待结转成本，后续产出成本为 0。
- 产出日期不得早于本批次领用日期；否则该产出单不会结转成本。系统只做提示、不阻断。
- 批次关闭后，该批次的领用与产出单不能新增、编辑或删除；关闭时剩余待结转一次性转入本批次方木池。

### 编号规则

- 编号 `PR` + 连字符 + 5 位全局流水（如 `PR-00001`），不含日期；只读、永不复用。
- 删除为软删除，编号不回收；产出明细随主记录软删。
- 格式口径见 `1-产品文档.md`「五、全局编号规范」；本域登记前缀 `PR`（方木产出）。

### 页面设计

按 `product/平台布局.md` 页面模式规范执行，本页特有口径如下：

- **列表页（PC，`/admin/production/outputs`）**：筛选 = 产出日期区间（标准筛选条：日期起 / 至、查询、重置）+ 生产批次；操作区 = 新建 + 选中后批量删除，右端 =「方木成本口径说明」链接按钮（弹窗说明，只读）；列 = 编号、生产批次、产出日期、明细行数、产出总方数、本次结转金额、备注、创建时间；产出日期倒序；首列多选（本页全选，翻页 / 改筛选即清空）；合计行汇总产出总方数；行操作 = 查看 / 编辑 / 删除，删除与批量删除均二次确认，文案说明编号不回收。
- **表单页（PC，`/admin/production/outputs/new`、`/[id]/edit`）**：标题 =「新建方木产出」/「编辑方木产出 + 编号」；主表字段 = 产出日期、生产批次（必选进行中批次）、备注；产出明细 = 表格式行编辑，列 = 长度（mm）、宽度（mm）、高度（mm）、根数、方量（只读）；「添加产出明细」按钮放明细标题下方左侧；行操作 = 复制 / 删除（图标按钮）；复制为整行深拷贝并追加末尾，达 200 行不可复制；明细区最大高度约 420px、超出在容器内滚动、表头固定；底部合计条右对齐显示产出总方数；校验：日期必填、批次必选、至少一行产出、长宽高为 > 0 的整数、根数 ≥ 1；保存前若所选批次无待结转成本、或产出日期早于本批次最近一笔原木领用，二次确认提示（说明产出将按 0 成本入库 / 成本不会结转到本单），确认后仍可保存；表单待结转提示明确「每次产出把本批次待结转一次性全额转入本批次方木池、不做部分结转」；保存成功跳详情。
- **详情页（PC，`/admin/production/outputs/[id]`）**：标题 = 编号；信息条 = 产出日期、生产批次（链接到批次详情）、产出总方数、本次结转金额、创建时间、备注；有结转时显示「来源领用单」——按推导列出领用单编号（纯文本展示，不跳转）；主体 = 产出明细表（列：行序、长度、宽度、高度、根数、方量）；删除只在列表行操作。
- **移动页（`/m/production/outputs`）**：入口 = `/m/production`「方木产出」；顶部栏右侧 =「口径说明」非主操作入口；列表 = 卡片按产出日期倒序（顶行 = 产出日期，主行 = 编号 + 总方数，次行 = 批次编号 + 明细行数 + 本次结转金额）+「加载更多」+ 底部固定「新建方木产出」；不设筛选组与批量操作；表单 = 单列，日期、批次、备注各占整行，明细上方显示所选批次待结转金额（无待结转时提示先录本批次领用），产出明细逐行卡片（行头 = 行序号 + 复制 / 删除，行内两列栅格放长 / 宽 / 高 / 根数，卡片底部显示该行方量），底部固定条常驻产出总方数与「保存」，保存前提示与 PC 同口径；详情只读，信息条含批次、本次结转金额与来源领用单，底栏 = 编辑（主色）/ 返回列表（描边），`production:manage` 时内容区提供「删除方木产出单」（整行描边红字，二次确认）。
- **方木成本口径说明弹窗（弹窗说明，只读）**：入口在方木产出列表页——PC 操作区右端、移动顶部栏右侧，移动端复用同一弹窗；三组——① **方木池的钱从哪来**：期初方木进入期初库存批次 + 领用时按「领用吨数 × 当时原木平均成本」记入本批次待结转、产出时全额转入 + 盘点调整按批次先进先出分摊；销售出库按批次先进先出扣方数与材料成本；② **为什么按批次算**：一个批次一个成本对象，批次平均成本 = 本批次金额 ÷ 本批次方数，批次之间不混摊；销售按批次日期先进先出扣层，老批次先卖；③ **两个时间点的影响**：领用后、产出前本批次待结转不计入库存总值，总值短暂减少，产出后恢复；产出把本批次待结转一次性全额转入，同一批次分多张产出单时第一张拿走全部；批次关闭后剩余待结转一次性转入；产出日期不得早于本批次领用日期；收尾一句：本页回答「方木入库的方数与成本怎么来」，批次余额看「生产批次」，库存总值看库存页；底部只有「关闭」。
- **权限**：查看 `production:view`；新建 / 编辑 / 删除 `production:manage`。

### 边界

- 不做生产排班、工序、机台、班组、计件、设备与仓库；生产批次仅作为成本对象，不是排产单。
- 不录毛尺寸或毛方数；加工损耗通过净方成本体现；后续若需出材率，另立需求或在本文档增补可选字段。
- 采购单不指定批次；领用与产出必须归属生产批次；产出单不直接关联单张领用单，按批次归集。
- 同一批次内约定一批领用对应一张产出单（可多行规格）；同一批次分多张产出单时第一张拿走全部待结转成本，后续产出成本为 0，系统只做保存前提示。
- 产出日期必须晚于本批次领用日期；日期早于本批次最近一笔领用时只提示、不阻断。
- 批次关闭后锁定该批次的领用与产出；剩余待结转一次性转入本批次方木池，之后仍可销售该批次库存。
- 产出单不改变采购单、销售单数据。

## R-生产-006：生产批次（轻量成本对象）

### 口径

- 一个生产批次是**一个成本对象**：原木领用与方木产出必须选择同一批次，批次之间成本不混摊。
- 批次可包含多张原木领用单与多张方木产出单；不建 BOM、工序、人工与制造费用。
- 批次编号 `BT` + 5 位流水，系统生成、只读、永不复用；期初库存批次也使用该序列。
- 批次状态：进行中 / 已关闭。只有进行中批次可以新增领用与产出；已关闭批次锁定全部单据。
- 期初方木自动归入「期初库存批次」（系统自动创建、只读、不可挂领用 / 产出）。
- 每个批次独立记录待结转与方木成本池；批次平均成本 = 本批次方木金额 ÷ 本批次方木方数。
- 销售出库按批次日期先进先出扣层：先卖老批次，卖完再卖新批次；每层按该批次平均成本计价。
- 关闭批次：`production:manage` 可关闭；关闭前若仍有待结转但没有方木库存，拒绝关闭并提示先录产出或删除领用；否则剩余待结转一次性转入本批次方木池。
- 盘点不参与待结转；方木盘点差异按批次日期先进先出分摊到各批次。

### 页面设计

- **列表页（PC，`/admin/production/batches`）**：标准日期筛选条（批次日期区间）+ 状态（全部 / 进行中 / 已关闭）；操作区 = 新建生产批次（弹窗）+ 选中后「批量关闭（N）」；列 = 编号、批次日期、类型、状态、方木方数、方木金额、平均成本、待结转、领用 / 产出单数、备注；批次日期倒序；首列多选（本页全选，翻页 / 改筛选即清空）；行操作 = 查看 / 编辑（弹窗，仅进行中）/ 关闭批次（仅进行中）。
- **新建 / 编辑（PC 弹窗）**：列表与详情共用同一弹窗，不设独立表单页与路由；标题 =「新建生产批次」/「编辑生产批次 + 编号」；字段 = 批次日期、备注；编号由系统生成；校验：日期必填；保存成功后关闭弹窗并刷新列表；已关闭批次不能编辑。
- **批量关闭（PC）**：选中若干批次后点「批量关闭（N）」，二次确认文案说明「已关闭的批次自动跳过、剩余待结转一次性转入各批次方木池」；任一所选批次「待结转 > 0 且无方木库存」时整批拒绝并提示先录产出或删除领用，不做部分成功。
- **详情页（PC，`/admin/production/batches/[id]`）**：信息条 = 批次日期、类型、状态、关闭时间、方木方数、方木金额、平均成本、待结转、关闭结转、备注；操作 = 编辑（弹窗，进行中）、关闭批次（进行中）、返回列表；主体 = 领用列表、产出列表、方木明细；关闭批次二次确认，说明剩余待结转将一次性转入本批次方木池。
- **移动页（`/m/production/batches`）**：入口 = `/m/production`「生产批次」；列表卡片（顶行 = 批次日期 + 状态徽标，主行 = 编号 + 方木方数，次行 = 批次金额 + 待结转）+ 加载更多 + 底部「新建生产批次」（与 PC 共用同一弹窗）；详情只读信息条 + 领用 / 产出 / 方木明细；底栏 = 编辑（主色，弹窗）/ 返回列表（描边），关闭批次放内容区（整行描边红字 + 二次确认）；移动端不设批量关闭。
- **权限**：查看 `production:view`；新建 / 编辑 / 关闭 / 批量关闭 `production:manage`。

## 待补与归属注记

- **毛尺寸与出材率**：本期不录毛尺寸；若后续需要看出材率，在方木产出单增补可选毛方数字段，仅展示、不参与库存扣减。
- **产品管理与板条**：产品类型扩展、规格主数据另立需求；本期只做方木。
- **人工与费用分摊**：工资、计件、固定人工、电费、运费、房租等归 payroll / finance 后续需求；本期材料毛利不含这些成本。
- **库存估值进入财务报表**：本期库存估值是管理视图；若未来进入财务成本与毛利，按新需求与 ADR 另立。
- **安全库存与预警**：本期不做；未来可基于库存数量与消耗速度另立。
- **生产批次与排产**：轻量生产批次已落地（R-生产-006），仅作成本对象；排产、工序、机台仍不做。
- **销售单与方木产出单关联**：不强制关联单张产出单；销售出库按批次日期先进先出扣层，成本来源记录在销售单成本层明细。
