# 平台布局领域（platform）

> 定位：平台布局与导航领域的**需求**（What）。实现设计见 `design/平台布局.md`。
> 编号规则：`R-平台布局-NNN`
> 范围界定：平台整体框架的**设计意图**（怎么分区、菜单怎么组织）；各页面内部的字段与交互设计归各自领域文档（`product/<领域>.md`），前端代码组织见技术方案 §7。本领域无后端模块。

## R-平台布局-001：平台整体布局与导航

### 整体布局（经典三区后台）

- **左侧边栏（固定）**：顶部 Logo 区 + 侧边导航（业务分组 + 菜单项）；分组可上下折叠——展开态点组标题、图标态点组图标，默认全部展开；边栏整体可横向折叠为图标栏、随时展开，折叠开关在顶栏左侧；菜单与面包屑走客户端导航，折叠状态本地记住（刷新保持）

- **顶部顶栏**：面包屑（层级 = 梅好木业 / 分组 / 菜单项 / 页面标识；上级可点击，当前页纯文本；页面标识如单据编号、「新建」「编辑」由所属页面提供）+ 右侧账号头像（下拉：修改密码、退出登录）；不设页面标题

- **主内容区**：按页面模式承载——列表页为筛选区 + 批量操作区 + 表格，表单/详情页为内容主体；内容区滚动，边栏与顶栏固定

- **无横向滚动（硬约束）**：任何页面、任何窗口宽度下不得出现页面级横向滚动条；超宽内容一律在内部容器滚动（表格容器、明细区）。长文本截断仅限列表页表格（单行、行高一致、悬停 title 显示全文）；表单与明细区的行内编辑控件不截断

### 菜单结构与领域归属

菜单按**业务领域**分组，与业务领域一一对应；平台机制（登录、布局）不设侧边菜单分组，修改密码与退出登录走顶栏头像（归账号与权限）。领域需求文档未建（`product/<领域>.md` 不存在）的分组不列入菜单表，随该领域首个真实需求创建后登记。

首页（登录后落地页）作为独立菜单项置顶，不属业务分组。

| 分组 | 菜单项 | 页面                         | 归属                          |
| -- | --- | -------------------------- | --------------------------- |
| —  | 首页  | 静态欢迎页（欢迎语 + 当前登录用户名，纯组件拼装） | 本领域（platform）               |
| 订单 | 销售单 | 成品销售单列表页                   | `product/order.md` R-订单-001 |

页面归属唯一（判定见 `0-文档驱动开发机制.md`）：首页静态欢迎页不围绕业务实体、随平台导航变化，归本领域；销售单列表页围绕销售单实体，归 order 域。新建/详情为列表页内跳转，不单列菜单项。

- 每个菜单项对应一个页面，页面的字段、录入与交互设计归所属领域文档，本节不重复定义

### 页面模式规范

全站页面模式统一由本节维护，当前三种（列表 / 表单 / 详情）。新页面形态（如特殊列表、聚合页、看板）按需在本节增补为**独立模式**，仍受全局约束（无横向滚动、组件库、对齐、操作列规范）；各领域页面设计（`product/<领域>.md`）只引用模式并补充字段与交互口径，不自行定义形态。组件组装清单见 `design/平台布局.md`。

**列表页**（筛选 → 批量操作 → 表格 → 分页）

- 结构自上而下：筛选区 → 批量操作区 → 表格区 → 分页区；不设页面标题

- 筛选区：字段组单行横排；每个字段组内为「标签左、控件右」左右并排（标签用次要色小字，标签与控件间距 8px）；键盘回车即查询；右端固定「查询」按钮，与字段组垂直居中，查询后重置到第 1 页

- 批量操作区：位于筛选区下方、左对齐；放新建等主操作；有选中行时出现批量删除（红色），删除前二次确认并提示条数与不可恢复；翻页、改筛选或改排序即清空选择

- 表格：首列为多选复选框，表头复选框为本页全选；文本列左对齐，数字与金额列右对齐（tabular-nums）；表头粘性固定（表体内部纵向滚动时始终可见）；可排序列（如日期、金额）点击表头切换正序/倒序并显示方向箭头，默认按业务日期倒序；备注等长文本列可截断（单行、行高一致，悬停 title 显示全文）；每行操作放末列——主要动作为图标按钮（配 aria-label 与 title，如查看 = Eye、编辑 = Pencil、删除 = Trash2 红色），语义不直观的动作才用文字按钮；空态显示「暂无 <实体名>」；加载态显示在表格内；表格超宽时在表格容器内横向滚动
- 表格合计行（固定）：表格区设最大高度（约 60vh），表体在表格容器内纵向滚动；底部合计行粘性固定（滚动始终可见），对数值列做汇总（标签放首个文本列），合计范围为当前筛选条件下的全部数据（由接口返回，不是仅当前页）；无数值列的数据可省略合计行

- 分页区：居左下；上一页 / 下一页 + 「第 x / y 页 · 共 n 条」；每页默认 20 条

- 删除一律二次确认；提醒删除后不可恢复、编号不回收；不弹成功回执

**表单页**（新建与编辑共用同一组件）

- 结构：主表区 → 明细/关联区（如有）→ 合计区（如有）→ 错误提示 → 操作区

- 主表区：字段栅格横排（宽屏默认 2 列），Label 与控件左右并排、不上下堆叠；必填不做红色星标，保存时校验失败给出中文提示

- 明细区：表格式行编辑，行可增删；「添加 ×× 行」按钮组放明细标题下方左侧（与列表页批量操作区同风格）；明细区限制最大行数（默认 50 行）与最大高度（约 420px），超出在明细区内滚动，表头粘性固定；行内编辑控件不截断（紧凑字号与图标化行操作保证完整显示）——数字输入不用步进器、每类控件按字段留足最小宽度，最窄窗口下由明细容器内部滚动兜底；底部合计条右对齐展示汇总值

- 操作区：位于页面末尾，保存 / 取消左对齐

- 校验：边界校验用 `@mcc/shared` 的 zod schema（保存时执行）；错误提示一条显示在操作区上方（取首条信息）

- 保存成功跳转详情页、不弹提示；取消回来源页（新建 → 列表，编辑 → 详情）

**详情页**（只读）

- 结构：标题（实体编号 + 关键属性括注）→ 信息条（关键汇总字段横排）→ 主实体表格 → 关联业务表格（如明细）

- 操作区（编辑 / 返回列表）位于页面末尾，与表单页操作区同位，不置页头

- 页面设计中字段级口径归各自领域文档，本节不重复定义

### 使用端

- 本平台为 PC 优先后台（录入、对账、报表均为密集表格与批量操作）；移动端现场操作类功能（如报工、拍照录入）后续做移动专属页（见技术方案 §7.3），不在本平台布局内

- 未登录访问一律跳转登录页；登录页归属账号与权限领域（见 `product/账号与权限.md`）
