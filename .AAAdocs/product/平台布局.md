# 平台布局领域（platform）

> 定位：平台布局与导航领域的**需求**（What）。实现设计见 `design/平台布局.md`。
> 编号规则：`R-平台布局-NNN`
> 范围界定：平台整体框架的**设计意图**（怎么分区、菜单怎么组织）；各页面内部的字段与交互设计归各自领域文档（`product/<领域>.md`），前端代码组织见技术方案 §7。本领域无后端模块。

## R-平台布局-001：平台整体布局与导航

### 整体布局（经典三区后台）

- **左侧边栏（固定）**：顶部 Logo 区 + 侧边导航（业务分组 + 菜单项）；分组可上下折叠——展开态点组标题、图标态点组图标，默认全部展开；边栏整体可横向折叠为图标栏、随时展开，**折叠开关在侧边栏底部**（展开态显示「收起」文字 + 图标，折叠态只显示图标）；折叠为图标栏时以**树状结构线**表示「业务分组 → 菜单项」的父子层级；菜单与面包屑走客户端导航，折叠状态本地记住（刷新保持）

- **顶部顶栏（两行）**：
  - **第一行**：多标签页 + 右侧账号头像（下拉：修改密码、账号管理（仅管理员）、审计日志（仅管理员）、退出登录）；页签只显示标题、不带图标；当前标签高亮
  - **第二行**：面包屑（层级 = 首页 / 分组 / 菜单项 / 页面标识；上级可点击，当前页纯文本；页面标识如单据编号、「新建」「编辑」由所属页面提供；当前页为首页时只显示一个「首页」）
  - 不设页面标题；不提供「关闭全部」「关闭其他」入口

- **主内容区**：按页面模式承载——列表页为筛选区 + 批量操作区 + 表格，表单/详情页为内容主体；内容区滚动，边栏与顶栏固定

- **视觉基线（纯白 + 强结构）**：画布纯白，**侧栏与表头为浅灰骨架**（极浅灰底），形成「骨架—内容」两层；容器、行分隔、输入框为三级边框；静态容器**不使用阴影**，层级只靠边框、留白与字重表达；**仅主操作（新建 / 保存 / 编辑）用品牌绿实心**（`--mcc-color-primary`，`#16653c`）；查询等次级动作可用浅灰实心（secondary），其余按钮一律描边；除主操作绿、状态点与危险操作外保持灰阶。内容区边距 28px，列表行高 44px、表头 40px，卡片圆角 8px、按钮与输入框圆角 6px；数字一律等宽右对齐（`tabular-nums`）。**内部滚动容器使用细滚动条**：默认淡、悬停或聚焦时加深，不做完全隐藏、不自绘假滚动条；标签栏的滚动条按「多标签页」规则单独隐藏，两者不冲突

- **无横向滚动（硬约束）**：任何页面、任何窗口宽度下不得出现页面级横向滚动条；超宽内容一律在内部容器滚动（表格容器、明细区）。长文本截断仅限列表页表格（单行、行高一致、悬停 title 显示全文）；表单与明细区的行内编辑控件不截断

### 多标签页（顶栏第一行）

- **生成**：点菜单或进入任意页面即生成标签；同一路径只保留一个标签，重复进入只激活已存在的标签
- **标题**：菜单项名 + 页面标识，以「 / 」连接——列表 = `销售单`；新建 = `销售单 / 新建`；详情 = `销售单 / 单号`；编辑 = `销售单 / 单号 / 编辑`；页面未提供标识时只显示菜单名
- **切换体验**：详情 / 编辑等已访问页面在切回标签时**立即呈现上次内容**（缓存优先、后台静默刷新），不得出现整页加载态；切回时恢复该标签上次的滚动位置
- **关闭**：每个标签可单独关闭；关闭当前标签后跳到相邻标签——右邻优先，其次左邻，都没有则回首页；关闭非当前标签不改变当前页
- **首页标签**：固定最左、始终存在、不可关闭
- **上限与淘汰**：最多 12 个标签；超出时自动淘汰最久未使用的标签（首页不参与淘汰），再插入新标签
- **溢出与截断**：标签总宽超出可视宽度时，标签栏**不显示滚动条**，两端出现左右切换按钮（到边界禁用，点击按可视宽度约 80% 滚动）；激活标签自动滚入可视区；**不得产生页面级横向滚动**；单个标签超长截断、悬停显示全文；面包屑同理（超长截断 + 悬停全文）
- **刷新保留**：标签列表与当前标签在浏览器会话内保留（刷新不丢）；退出登录、修改密码成功后清空
- **不提供**「关闭全部」「关闭其他」入口
- **已知代价**：表单页未保存的内容在切走标签后丢失（不做页面保活）；列表页的筛选 / 分页状态切走后重置（后续以 URL 参数 + 缓存改进）

### 菜单结构与领域归属

菜单按**业务领域**分组，与业务领域一一对应；平台机制（登录、布局）不设侧边菜单分组，修改密码与退出登录走顶栏头像（归账号与权限）。领域需求文档未建（`product/<领域>.md` 不存在）的分组不列入菜单表，随该领域首个真实需求创建后登记。

菜单图标**全局不重复**：首页、各业务分组、各菜单项之间不得复用同一图标（分组与其子项的图标尤其不能相同），以保证折叠为图标栏时可区分。

首页（登录后落地页）作为独立菜单项置顶，不属业务分组。

| 分组 | 菜单项 | 页面                         | 归属                          |
| -- | --- | -------------------------- | --------------------------- |
| —  | 首页  | 静态欢迎页（欢迎语 + 当前登录用户名，纯组件拼装） | 本领域（platform）               |
| 销售 | 销售单 | 成品销售单列表页                   | `product/order.md` R-订单-001 |
| 销售 | 客户档案 | 客户列表页                     | `product/customer.md` R-客户-001 |
| 采购 | 采购单 | 采购单列表页                     | `product/purchase.md` R-采购-001 |
| 采购 | 供应商 | 供应商列表页                     | `product/supplier.md` R-供应商-001 |
| 财务 | 资金流水 | 资金流水列表页（账户卡片 + 收付流水） | `product/finance.md` R-财务-002 |
| 财务 | 收支汇总 | 收支汇总报表页                   | `product/finance.md` R-财务-001 |

页面归属唯一（判定见 `0-文档驱动开发机制.md`）：首页静态欢迎页不围绕业务实体、随平台导航变化，归本领域；销售分组下销售单列表页围绕销售单实体，归 order 域；客户列表页围绕客户实体，归 customer 域；采购单列表页围绕采购单实体，归 purchase 域；供应商列表页围绕供应商实体，归 supplier 域；资金流水与收支汇总页围绕资金与收支，归 finance 域。新建/详情为列表页内跳转（或弹窗），不单列菜单项。

- 每个菜单项对应一个页面，页面的字段、录入与交互设计归所属领域文档，本节不重复定义

**权限可见性**（矩阵见 `product/账号与权限.md` R-账号与权限-003）：

- 侧边菜单、头像菜单项与页面内的新建 / 编辑 / 删除入口按角色 scope 裁剪；前端裁剪只影响可见性，服务端守卫是最终边界
- 直接访问无权限页面显示统一的无权限提示，不渲染页面内容
- 账号管理属平台机制页面，从顶栏头像下拉「账号管理」进入，不占侧边业务分组
- 审计日志同属平台机制页面，从顶栏头像下拉「审计日志」进入，不占侧边业务分组；仅 `audit:view`（管理员）可见
- 此后新增页面必须声明权限单元（view / manage）与各角色默认授权，并更新权限矩阵；未声明 scope 的页面视为未完成

### 页面模式规范

全站页面模式统一由本节维护，当前为列表 / 主从列表 / 表单 / 详情 / 聚合页 / 移动页六种，另有弹窗表单、弹窗详情与打印预览弹窗三种覆盖层形态。新页面形态（如看板、特殊列表）按需在本节增补为**独立模式**，仍受全局约束（无横向滚动、组件库、对齐、操作列规范）；各领域页面设计（`product/<领域>.md`）只引用模式并补充字段与交互口径，不自行定义形态。组件组装清单见 `design/平台布局.md`。

**列表页**（筛选 → 批量操作 → 表格 → 分页）

- 结构自上而下：筛选区 → 批量操作区 → 表格区 → 分页区；不设页面标题

- 整页弹性布局：列表页纵向撑满主内容区，筛选区 / 批量操作区 / 分页区各按内容高度，表格区占满剩余高度；页面本身不出现纵向滚动，纵向滚动只发生在表体内部（窗口过矮时表格区收缩至最小高度约 240px，再矮由主内容区滚动兜底）

- 筛选区：字段组单行横排；每个字段组内为「标签左、控件右」左右并排（标签用次要色小字，标签与控件间距 8px）；键盘回车即查询；右端固定按钮组「查询（secondary）→ 重置（outline）」，与字段组垂直居中；查询后重置到第 1 页；**重置 = 恢复本页默认筛选 → 立即查询 → 回第 1 页 → 清空已选行**（保留当前排序；默认值由所属领域定义，通常为空，汇总类页面回默认区间）

- 批量操作区：位于筛选区下方、左对齐；放新建等主操作；有选中行时出现该领域定义的批量动作（如批量删除、批量启用/停用），危险或阻断性动作用红色；动作执行前按「二次确认规范」确认；翻页、改筛选或改排序即清空选择

- 表格：首列为多选复选框，表头复选框为本页全选；文本列左对齐，数字与金额列右对齐（tabular-nums）；**表头使用浅灰底**（与内容行区分）并粘性固定（表体内部纵向滚动时始终可见）；**表格是列表页唯一的卡片容器**，筛选区与批量操作区内联在画布上，不单独成卡；可排序列（如日期、金额）点击表头切换正序/倒序并显示方向箭头，默认按业务日期倒序；备注等长文本列可截断（单行、行高一致，悬停 title 显示全文）；每行操作放末列——主要动作为图标按钮（配 aria-label 与 title，如查看 = Eye、编辑 = Pencil、删除 = Trash2 红色），语义不直观的动作才用文字按钮；空态显示「暂无 <实体名>」；加载态显示在表格内；表格超宽时在表格容器内横向滚动。**无批量动作的列表页可省略首列多选与全选**（如账号管理），其余表格规范不变。
- 表格合计行（固定）：表头与底部合计行均粘性固定（表体在表格容器内纵向滚动时始终可见），对数值列做汇总（标签放首个文本列），合计范围为当前筛选条件下的全部数据（由接口返回，不是仅当前页）；无数值列的数据可省略合计行

- 分页区：居左下；上一页 / 下一页 + 「第 x / y 页 · 共 n 条」；每页默认 20 条

- 删除一律二次确认（见「二次确认规范」）；提醒删除后不可恢复、编号不回收；不弹成功回执

**主从列表页**（左栏主列表 + 右栏标准列表）

- **适用判定**（四条同时满足）：左右存在稳定归属关系（如资金账户 → 资金流水）；左栏条目少且稳定（建议 ≤ 50，不分页）；左栏某一项可作为右栏的查询条件；左栏自身可新建 / 编辑且适合弹窗
- **布局**：整页左右两栏（左窄右宽），共用**一个外层卡片**，内部用竖线分隔，两栏之间不留间隙；左栏固定宽约 240px，右栏占满剩余宽度；两栏各自内部滚动，页面本身不滚动；页面级不出现横向滚动（表格超宽时按列表页规则在表格容器内滚动）
- **左栏**：卡片头为「标题在左、新建按钮在右」；列表首项为「全部」并默认选中；行内容简洁（主文本 + 状态标记，金额等数值默认不进左栏，是否展示次要信息由领域定义）；「全部」行可显示数量摘要并加粗；选中态 = 浅色底 + 左侧竖条；点击某项即作为右栏查询条件并使右栏回第 1 页、清空已选行；行内操作收进所在行行尾的「⋯」溢出菜单（至少含查看详情、编辑，领域可增补停用 / 启用、删除等），菜单点击不触发筛选；不做分页、不做搜索
- **右栏**：完整沿用列表页规范（筛选区、批量操作区、表格、合计行、分页、主操作）；表格滚动行为与普通列表页一致，不因双栏改变；**不再重复左栏维度的筛选字段**，该维度只由左栏承担；编号点击与行内「查看」打开详情弹窗
- **重置**：右栏「重置」= 恢复本页默认筛选 → 立即查询 → 回第 1 页 → 清空已选行，并把左栏恢复为「全部」
- **联动**：右栏新建默认带入左栏当前选中项；右栏数据变化后左栏的派生信息（如状态、数量）同步刷新

**表单页与详情页共用骨架**：页面纵向撑满主内容区；标题区与底部操作区固定，中间内容区独立滚动；页面本身不出现纵向滚动；任何窗口宽度下不出现页面级横向滚动。标题区内容（动作名、单据编号、实体名称等）由所属领域文档定义。

**表单页**（新建与编辑共用同一组件）

- 结构：固定标题区 → 可滚动内容区（主表区 → 明细/关联区（如有）→ 合计区（如有）→ 错误提示）→ 固定操作区

- 标题区：动作名 + 页面标识（如「新建销售单」「编辑销售单 SO-00010」），随页面内容固定，不随内容区滚动

- 主表区：字段栅格横排（宽屏默认 2 列），Label 与控件左右并排、不上下堆叠；必填不做红色星标，保存时校验失败给出中文提示

- 明细区：表格式行编辑，行可增删；「添加 ×× 行」按钮组放明细标题下方左侧（与列表页批量操作区同风格）；明细区限制最大行数（默认 200 行）与最大高度（约 420px），超出在明细区内滚动，表头粘性固定；行内编辑控件不截断（紧凑字号与图标化行操作保证完整显示）——数字输入不用步进器、每类控件按字段留足最小宽度，最窄窗口下由明细容器内部滚动兜底；底部合计条右对齐展示汇总值

- 操作区：固定于页面底部（不随内容区滚动），保存 / 取消左对齐，上边框与内容区分隔；打印时隐藏

- 校验：边界校验用 `@mcc/shared` 的 zod schema（保存时执行）；错误提示一条显示在操作区上方（取首条信息）

- 保存成功跳转详情页、不弹提示；取消回来源页（新建 → 列表，编辑 → 详情）

**详情页**（只读）

- 结构：固定标题区（实体编号 + 关键属性括注）→ 可滚动内容区（信息条 → 主实体表格 → 关联业务表格）→ 固定操作区

- 标题区：实体编号 + 关键属性括注（如「销售单 SO-00001（客户名）」），不随内容区滚动

- 关联业务表格（如销售单明细）：最大高度约 420px，超出在表格容器内滚动，表头粘性固定；信息条随内容区滚动

- 操作区：固定于页面底部（不随内容区滚动），编辑 / 打印 / 返回列表左对齐，上边框与内容区分隔；打印时隐藏

- 页面设计中字段级口径归各自领域文档，本节不重复定义

**聚合页**（报表 / 看板）

- 结构：筛选区（如日期区间）→ 指标卡片区（关键数值横排，2~4 张）→ 明细或分组表格 →（可选）分页
- 不设页面标题；筛选区口径同列表页（字段组标签左、控件右，回车即查询）
- 指标卡片区：每卡 = 指标名（次要色小字）+ 数值（大号等宽数字）；卡片即容器，内部表格不再套卡
- 宽度：卡片区与表格**铺满内容区宽度，不设最大宽度**
- 高度：整页弹性布局（同列表页）——筛选区与卡片区按内容高度，表格区占满剩余高度并在表体内纵向滚动（最小高度兜底）
- 辅助说明（事件条数、口径注记等）放**卡片区下方右侧**小字，不挤在筛选行内
- 表格沿用列表页表格规范（对齐、表头固定、可排序列）；合计行按领域口径可省略（如收支汇总由顶部指标卡承担汇总）；具体指标与分组口径由所属领域文档定义
- **页内 Tab**：同一页面承载两个口径 / 视图时，可在页面内使用 Tab 分区（如收支汇总拆「经营收支 / 资金收付」）。Tab 位于筛选区下方、内容区上方；只切换内容区，不新增顶部多标签页、不新增菜单项；Tab 状态写入 URL（如 `?tab=funds`），刷新与深链保留，非法值回默认；各 Tab 独立筛选与分页，默认 Tab 由领域定义

**弹窗表单与弹窗详情**（字段少、无明细的实体）

- **适用判定（表单）**（三条同时满足才用弹窗）：字段数 ≤ 6 且无明细 / 子表；无跨页面跳转与复杂联动；不需要 URL 直达（不分享、刷新不保留）。任一条不满足即用独立页面（如销售单表单）；拿不准用页面
- **适用判定（详情）**：字段 ≤ 8、无明细 / 关联表、不需要 URL 直达；否则用独立详情页（如销售单、客户）
- **形态**：居中弹窗（最大宽约 520px），只保留这一种覆盖层形态，不引入抽屉；表单标题 = 动作名（如「新建资金流水」「编辑资金流水」），详情标题 = 实体编号（可括注分类）
- **表单结构**：标题 → 字段区（Label 左、控件右，与表单页一致）→ 错误提示（操作区上方）→ 操作区（保存 / 取消，左对齐）
- **详情结构**：标题 → 信息条（Label 左、值右，与详情页信息条同口径）→ 操作区（编辑【有权限时】/ 关闭）；只读，不在弹窗内直接编辑字段
- **交互**：表单保存成功关闭弹窗并刷新列表，不跳转详情、不弹成功提示；取消 / ESC / 点遮罩关闭；有未保存改动时关闭需二次确认（确认框叠在弹窗之上）；**详情 → 编辑为状态切换**（关闭详情弹窗、打开编辑弹窗），不叠加嵌套；弹窗不产生面包屑页面标识、不新增多标签页标签；弹窗内禁止再开弹窗（二次确认除外）
- **取舍（明示）**：弹窗详情不提供单条 URL 直达与独立标签页——流水类记录不需要分享链接；需要直达与分享的实体仍用独立详情页

**打印预览弹窗**（单据打印）

- **适用**：需要按纸张版式打印的业务单据（如成品销售单）；只有一套版式时不提供模板选择
- **形态**：大尺寸弹窗（约占视口 90%、最大宽约 1200px），不产生面包屑页面标识、不新增多标签页标签；左侧为灰底 A4 预览区（白纸版式、等比缩放、可滚动），右侧为窄操作栏
- **操作栏**：标题「打印预览」、单据号、纸张（A4 纵向）与简短说明，操作 = 打印 / 关闭；ESC 与关闭按钮退出，其余交互同弹窗覆盖层规范
- **打印**：调起浏览器打印对话框；PDF 用「另存为 PDF」；份数由打印对话框决定；应用内不设份数、模板、价格显隐等选项（领域文档另有约定除外）；浏览器自带的页眉页脚（日期、标题、网址、页码）属浏览器设置，页面无法关闭，操作栏给出取消勾选提示
- **输出隔离**：打印只输出单据版式，不含弹窗遮罩、操作栏与后台壳；预览与打印共用同一模板组件（实现见 `design/平台布局.md`）
- **内容口径**：纸张、字段、联次、抬头与签字栏由所属领域文档定义，本节不重复

**移动页**（移动 Web，`/m`；适老化基线，ADR-011）

- **适用**：现场操作（如手机开成品销售单、查单）；PC 后台页面不做移动适配，移动页**独立设计**、不是 PC 页面的缩窄版

- **结构**：顶部栏（返回 + 页面标题或单据编号 + 右侧动作区：账号动作或页面动作，如新建）→ 单列内容区 → 底部固定操作区（主操作整行大按钮）

- **入口页**：`/m` 可挂多个业务卡片（如销售、采购、资金），按角色 scope 裁剪；一级卡片对应业务板块，二级入口页再列具体页面（如销售 → 销售单 / 客户档案）；入口页顶部栏右侧放「退出」
  - 二级入口页与入口页**同形**：同样挂业务卡片、整卡可点；页面跳转不用按钮承载，不设一实心一描边的主次暗示

- **列表**：整行搜索框（单行、回车即查，查询后回第 1 页；无搜索需求的列表可不放）+ 卡片列表（主信息大字、次要信息小字），整卡可点进详情；「加载更多」不做页码；统一空态与加载态；不设多选与批量操作；**新建等主操作一律放底部固定操作条（整行主按钮），顶部栏右侧只放非主操作（如入口页退出）**

- **退出登录**：仅入口页 `/m` 顶部栏右侧提供「退出」；点击调登出接口、清会话并回登录页，不弹确认；其他移动页不提供账号动作

- **适老化基线**：正文不小于 16px（关键数值更大）；触控目标不小于 44×44px、主按钮高度不小于 48px；文字与控件边界的对比度高于 PC 基线；一律单列，不设左右并排字段与密集表格

- **表单**：Label 在上、控件在下并占满整行；数字字段使用数字键盘（`inputMode="numeric"`）；明细不用表格，改为逐行卡片（行内字段两列栅格），行操作用图标 + 文字；底部固定条常驻显示合计（方量 / 金额）与「保存」
- **分段切换**：在少量互斥大类之间切换时（如结算方式「赊销 / 现结」、收支汇总「经营收支 / 资金收付」），用整行等宽的分段按钮，**不用 PC 页内 Tab、不用下拉**；每个按钮高不小于 48px，选中态为实心主色底 + 白字，未选中为描边；选项不超过 4 个，4 个时排两行两列（每格仍不小于 48px），超出改用独立页面或列表选择
- **移动弹窗**：复用 PC 弹窗的内容与形态，宽度自适应且不超过视口宽度减两倍页边距；内容超出视口时在弹窗内部纵向滚动，不带动整页滚动；底部按钮高不小于 48px
- **字号与控件角色**（数值唯一出处在 `packages/tokens`，文档与页面只引用角色，不写具体像素）：

  | 角色 | 用途 | 相对关系 |
  | --- | --- | --- |
  | title | 页面与区块标题、列表主行（日期 / 客户名 / 账户名） | 与正文同级、加粗 |
  | body | 正文、表单值、信息行值、列表次行 | 基准 |
  | label | 字段标签、辅助说明 | 小于正文 |
  | caption | 状态标签、极次要信息 | 最小 |
  | numeric | 金额等数值 | 大于正文；汇总大数用同角色的强调变体，不新增角色 |

  - 底线：body 不小于 16px；触控目标不小于 44×44px；输入、下拉与主按钮高 48px；入口大按钮与分段控件可到 56px；对比度高于 PC
  - 例外：领域文档可声明本页偏离某角色，必须写明理由；未登记的偏离视为缺陷
  - 变更：新增角色须在本文档 changelog 记一行并在 tokens 加变量；禁止页面内写任意像素字号
- **导航**：无侧边栏、无多标签页、无面包屑；页面间经顶部返回与入口页 `/m` 进出；登录后按视口宽度分流到 PC 后台或移动入口

- **不做**：横向滚动、依赖 hover 的交互、字号切换开关（适老化是默认基线，不是模式）

### 二次确认规范

全站需要用户确认的动作统一走本规范，**禁止使用浏览器原生 confirm / alert / prompt**（实现见 `design/平台布局.md`）。

**需要确认的判定**（满足任一条）：

| 条件 | 例子 |
| --- | --- |
| 不可恢复 | 删除、批量删除 |
| 阻断业务 | 停用客户、批量停用 |
| 影响多条 | 任意批量动作（含批量启用） |

单条恢复性动作（如启用客户）不确认，减少操作噪音。

**文案结构**

- 标题 = 动作名，不加问号（如「停用客户」「删除销售单」）
- 正文 = 对象 + 数量 + 影响（如「将停用选中的 8 个客户，停用后不可被新销售单选择」）
- 不可恢复动作补一句后果（如「删除后不可恢复，编号不回收」）

**按钮与焦点**

- 左「取消」、右动作名（如「停用」「删除」），不使用「确定 / 否」这类无信息量的词
- 危险或阻断性动作用红色确认按钮
- 默认焦点落在「取消」，防手滑回车

**交互**

- 确认后执行中：按钮禁用并显示处理中，防重复提交
- ESC、点击遮罩、点「取消」均视为取消，不执行
- 执行失败在页面内提示，不再弹窗；成功不弹回执
- 批量动作遇混合状态：按目标状态幂等处理，已处于目标状态的记录跳过；确认正文给出「将变更 N 个、跳过 M 个」；无任何将变更时对应按钮禁用

### 使用端

- **两个使用端**：PC 后台（`/admin`，本布局的三区壳）与**移动 Web**（`/m`，手机浏览器直接访问，不做小程序 / App）。PC 后台承载录入、对账、报表等密集表格与批量操作；移动端承载现场操作（如手机开单），页面按「移动页」模式执行，独立壳（无侧边栏 / 多标签页 / 面包屑）

- **适老化只在移动端**：移动端默认即为适老化基线（见「移动页」），不提供用户可切换的适老模式；PC 后台不做适老化（ADR-011）

- 登录页两端共用；登录成功后按视口宽度分流——窄屏进 `/m`，宽屏进 `/admin`

- 未登录访问一律跳转登录页；登录页归属账号与权限领域（见 `product/账号与权限.md`）
