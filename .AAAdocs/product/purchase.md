## R-采购-001：原木采购单

### 口径声明

- 采购通常**电话口头确认**，没有采购申请与审批；供应商把原木拉到厂里，现场质检、定价、确认吨数与单价后录入采购单，**采购单保存即视为入库**，系统不做入库单、不做库存（生产与库存后置，见 `.战略与经营/01第一阶段规划/业务调研-生产与库存.md`）。
- 采购单是**单头单据，无明细**：一张单对应一次过磅与一个结算单价，与成品销售单的一单多明细不同。
- 计价按**结算吨数**：送货吨数只记录实际过磅，结算吨数用于计价；两个吨数的差额即为折价，不再单独记录文字说明。
- **其他金额（运费等）计入合计，也计入对供应商的应付**；不区分付给供应商还是司机。
- 采购以**赊购为主、现结为辅**：现结保存时在财务侧派生一条采购付款流水；赊购不派生，后续手工付款挂供应商。
- 采购单可修改、可删除；修改与删除同步财务侧派生流水（见下）。

### 字段

| 字段 | 口径 |
| --- | --- |
| 采购单编号 | 系统生成 `PO-#####`，只读、永不复用 |
| 供应商 | 必选，只列启用供应商；保存时校验存在且启用；历史单据保留名称快照 |
| 采购日期 | 必填，默认当天 |
| 送货吨数 | 必填，大于 0，最多 3 位小数（实际过磅） |
| 结算吨数 | 必填，大于 0、不大于送货吨数，最多 3 位小数（计价） |
| 单价 | 元/吨，非负、2 位小数 |
| 小计金额 | 结算吨数 × 单价，四舍五入 2 位，只读 |
| 其他金额 | 运费等杂费，非负、2 位小数、默认 0 |
| 合计金额 | 小计金额 + 其他金额，只读 |
| 结算方式 | 现结 / 赊购，必选 |
| 现结账户 | 现结时必选，只列启用资金账户；赊购时不显示 |
| 实付金额 | 现结时必填，默认等于合计、可改，非负、2 位小数；差额作折让，只记在单据上 |
| 备注 | ≤500 字，可空 |
| 创建时间 | 只读 |

### 计算规则

- 小计 = 结算吨数 × 单价，四舍五入 2 位；
- 合计 = 小计 + 其他金额；
- 金额一律字符串 + BigInt 或整数放大运算，禁浮点；
- 累计采购口径（供 finance 引用）：现结单取实付金额、赊购单取合计金额，只统计系统内采购单；现结差额作折让，不构成应付。

### 一次录入、另一侧自动派生

| 结算方式 | 录入内容 | 自动派生 |
| --- | --- | --- |
| 现结 | 采购单 + 现结账户 + 实付金额 | 付款流水：方向付、分类采购付款、账户 = 现结账户、金额 = 实付、供应商 = 采购单供应商、备注 = 采购单编号、源单 = 采购单 |
| 赊购 | 仅采购单 | 不生成流水；后续手工付款走资金流水（分类采购付款、挂供应商） |

- 源单唯一：同一采购单最多派生一条付款流水，防重复；
- 源单流水在财务侧只读，只能回采购单修改或删除；
- 修改采购单：同步流水的日期、金额、账户、供应商；现结改赊购软删流水，赊购改现结补建；
- 删除采购单：派生流水一并软删，余额自动回退；
- 采购单不做状态机，保存即入库；删除为软删除。

### 页面设计

- **采购单列表（`/admin/purchases`）**：筛选 = 供应商 + 结算方式 + 采购日期区间（应用内日期选择器）；批量操作区 = 新建（左对齐），有选中行时出现批量删除（危险色，按钮带选中条数）；表格首列多选（本页全选，翻页 / 改筛选 / 改排序即清空选择）；列 = 编号（主色链接进详情）、采购日期、供应商、送货吨数、结算吨数、单价、合计金额（右对齐）、结算方式、操作；采购日期与合计金额表头可切换正 / 倒序（换列默认倒序、回第 1 页），其余列不排序；合计行为表格内粘性合计行（筛选全量合计金额）；行操作 = 查看 / 编辑 / 删除，删除与批量删除均二次确认，文案说明现结派生的付款流水一并删除、账户余额回退、编号不回收。
- **新建 / 编辑表单**：新建与编辑共用；标题 = 新建采购单 / 编辑采购单 + 编号；按销售单表单的分区骨架组织——「主单」区 = 供应商、采购日期、结算方式、现结账户与实付（现结时）、备注；「吨数与金额」区 = 送货吨数、结算吨数、单价、小计（只读）、其他金额，区底合计条右对齐显示合计金额；小计与合计随输入即时计算；控件宽度与销售单表单一致——标签左置右对齐，主单左列（编号 / 采购日期 / 结算方式 / 实付金额）与吨数金额区一律窄宽，主单右列（供应商 / 付款账户）一律中等宽度，同列上下等宽；备注用与销售单一致的文本域（最小单行高、可拖动拉高）；下拉与日期控件同高；日期用应用内日期选择器，默认值为本地时区的今天；PC 用 PageFrame，保存 / 取消与错误提示放固定操作区。
- **详情页**：与销售单详情同构——标题 = 「采购单 编号」+ 灰色小字「（供应商名）」；主信息卡（编号、供应商、采购日期、结算方式、现结账户与实付、创建日期、备注）+ 独立「吨数与金额」卡（送货吨数、结算吨数、单价、小计、其他金额、合计）；操作区 = 编辑 / 返回列表，删除只在列表行操作。
- **移动页**：
  - `/m` 一级入口「采购」卡片 → `/m/purchase` 二级入口（采购单 / 供应商两张整卡）；
  - 采购单列表 `/m/purchase/orders`、新建 `/m/purchase/orders/new`、详情 `/m/purchase/orders/[id]`、编辑 `/m/purchase/orders/[id]/edit`；
  - 移动列表卡片 = 供应商 + 采购日期 + 合计金额 + 现结 / 赊购标签；筛选只有一条供应商名称模糊搜索，交互与销售单列表一致（回车查询、清除、回第 1 页）；加载更多与空态按移动列表骨架；
  - 移动表单单列、控件高 48px、金额 `inputMode="decimal"`、日期用移动日期选择器且默认本地时区的今天、供应商用整行下拉（带编号与停用标记）；结算方式用分段控件；小计与合计只读展示；仅一个付款账户时自动选中；现结实付与合计不一致时提示抹零 / 预付；底部固定条显示合计金额与保存，校验与接口错误用固定浮层提示；
  - 移动详情固定标题「采购单详情」；主卡 = 供应商名称 + 采购日期 + 分隔线 + 结算方式 + 备注；「吨数与金额」独立分区 = 送货吨数、结算吨数、单价、小计、其他金额、合计；底部固定条只放编辑 / 返回列表，删除作为内容区危险操作（描边按钮 + 图标 + 二次确认 + 失败提示）；
  - 移动端不做批量；权限 `purchase:view` / `purchase:manage`。

### 与其他领域的边界

- **supplier**：采购单挂供应商，经 `assertSelectable` 校验；保留供应商名称快照，不直读 supplier 表。
- **finance**：采购单现结在采购单事务内调用 finance 公开方法生成 / 同步 / 软删付款流水，采购域不写流水表；累计采购、累计付款、应付归 finance（`R-财务-004`），采购单不建金额冗余列。
- **生产与库存**：本轮不建；采购单保存即入库，无库存回写。生产与库存上线后，已领用或已入库的采购单不允许直接删除，届时补守卫。
