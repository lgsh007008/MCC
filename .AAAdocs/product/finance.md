# 财务领域（finance）

> 定位：财务领域的**需求**（What）。实现设计见 `design/finance.md`。
> 编号规则：`R-财务-NNN`
> 范围界定：业务发生台账——收支事件的记录（系统自动生成 + 手工录入）与按日期区间的收支汇总。**本领域为管理会计口径，不做复式记账**：不建会计科目表、不做借贷平衡与期末结转、不出资产负债表与现金流量表、不用于对外报税；应收应付见文末待补注记。

## R-财务-001：业务发生台账与收支汇总

调研依据：`.战略与经营/01第一阶段规划/业务调研-财务台账.md`（原飞书三表 + 2026-11-10 架构讨论结论）。

### 口径声明（为什么不做复式记账）

- **定性**：本域是**单式流水台账**——一笔业务一条事件、金额正负表方向；属管理会计口径，不是会计核算账
- **与复式记账的差别**：主流 ERP（SAP、Oracle、NetSuite、用友、金蝶等）采用复式记账——记账凭证（借贷两行、金额必相等）+ 会计科目表，产出总账、明细账、资产负债表、利润表、现金流量表。复式存在的三个硬需求：① 追踪钱从哪来、到哪去（银行账户、往来、存货都能对上）；② 编制对外报表（报税、贷款、审计）；③ 借贷不平衡即刻暴露录入错误
- **本场景取舍**：自家小厂自建系统，无审计、无对外报表、无贷款报表需求；上复式需科目表、凭证、期末结转，录入成本翻数倍且需专业会计参与设计。故**当前不引入复式**，采用与小微企业实际一致的「流水 + 收支分类」
- **明示局限**：不出资产负债表与现金流量表、不做借贷平衡校验、不做银行对账、不能直接用于报税
- **三件执行口径**：
  1. **正名**：系统内一律称「业务发生台账」，不称「会计记账」
  2. **分类科目化**：分类按收入类 / 成本类 / 费用类组织（销售收入、其他收入；采购成本、人工成本；其他支出），粗粒度 + 备注，为将来升级留路
  3. **明确应计口径**：销售单确认即入账（含赊销），总收入 = 期间业务收入，不等于现金流入
- **金额与指标口径**：金额有符号（收入正、支出负）；总收入 = 正数金额合计；总成本 = 负数金额绝对值合计；净利润 = 总收入 − 总成本
- **升级路径**：未来若需对外报表（报税、贷款、审计），按 `2-adr.md` 新增 ADR 决策引入复式记账（科目表 + 凭证），本台账可平移为凭证的辅助记录

### 事件结构

| 字段 | 口径 |
| --- | --- |
| 事件编号 | 系统自动生成（年月+当月流水，如 202611-0001），只读、永不复用 |
| 发生日期 | 手填，默认当天 |
| 分类 | 枚举：销售收入 / 其他收入 / 采购成本 / 人工成本 / 其他支出 |
| 金额 | 2 位小数，有符号（收入正、支出负），不得为 0 |
| 备注 | 手填，写具体事由（如「锯末 3 吨」「维修裁板锯」） |
| 来源 | 自动 / 手工，只读 |
| 源单 | 自动事件记录源单（类型 + 编号，如「销售单 202611-0001」）；手工事件为空 |

分类与方向：销售收入、其他收入为正；采购成本、人工成本、其他支出为负。

### 两类事件

**自动事件**

- 销售收入：成品销售单创建时生成（金额 = 合计金额）；编辑销售单时同步更新；删除销售单时事件一并软删
- 同一源单只生成一条事件（源单唯一约束，防重复生成）
- 采购成本、人工成本：待采购域、payroll 域建成后接入（见待补注记）
- 自动事件只读：不允许在财务侧编辑或删除，一律以源单为准

**手工事件**

- 仅限「其他收入」「其他支出」两类（售卖锯末、柴火记其他收入；设备维修、杂费记其他支出）
- 可新建、编辑、删除（软删除）
- 系统类分类（销售收入 / 采购成本 / 人工成本）不允许手工录入

### 汇总

- 按日期区间实时计算，不落库、不存快照
- 指标：总收入、总成本、净利润、事件条数；辅助按分类小计
- 净利润 = 总收入 − 总成本

### 页面设计

按 `product/平台布局.md` 页面模式规范执行，本领域特有口径如下：

- **财务台账（列表页）**：筛选项 = 发生日期区间、分类、来源；列 = 事件编号、发生日期、分类、金额（带正负号，右对齐）、来源、源单、备注；可排序列 = 发生日期、金额；行操作 = 查看（弹窗）、编辑（仅手工事件，弹窗）、删除（仅手工事件）；编号点击打开详情弹窗；批量删除仅对手工事件可用，自动事件不可选；合计行汇总金额；**新建、编辑、详情均走弹窗**（关闭后列表就地刷新，保持筛选与分页）
- **手工记账（弹窗）**：分类（仅其他收入 / 其他支出）、发生日期、金额（按正数录入，保存时按分类转为有符号）、备注；保存成功关闭弹窗并刷新列表，不跳转详情；有未保存改动时关闭需二次确认；弹窗不产生面包屑标识、不新增标签页
- **收支汇总（聚合页）**：日期区间选择（默认本月）+ 查询；三张指标卡 = 总收入、总成本、净利润；下方分类小计表（分类、收入、成本、净额）；卡片区与表格铺满内容区，表格区占满剩余高度；事件条数与口径说明放卡片区下方右侧小字；面包屑标识：无（列表级）
- **详情（弹窗）**：标题 = 事件编号 + 分类括注；信息条 = 发生日期、分类、金额、来源、源单、备注；操作区 = 编辑（仅手工事件，切换为编辑弹窗，不嵌套）/ 关闭；只读展示，不提供单条 URL 直达与独立标签页（见 `product/平台布局.md` 弹窗规范取舍）

### 待补与归属注记

- **采购成本自动生成**：采购域建成后接入（采购单 → 成本事件）
- **人工成本自动生成**：payroll 域建成后接入（工资 → 成本事件）
- **应收应付**：`R-财务-002` 另立（客户欠款 = 销售累加 − 回款核减；供应商欠款同理），与订单、客户通过源单与客户关联
- **逆向冲减（红冲）**：枚举保留、本轮不启用（退货补货暂不纳入）
- **复式记账升级**：未来如需对外报表，按 ADR 决策引入，不在本需求内
