## R-托盘设计-001：托盘项目与结构模板

### 项目字段

| 字段 | 口径 |
| --- | --- |
| 项目编号 | 系统自动生成（`PD` + 连字符 + 5 位流水，如 `PD-00001`），只读、永不复用 |
| 项目名称 | 手填，必填，最多 100 字 |
| 客户名称 | 手填，可空，最多 100 字；只作展示，不建客户外键、不生成销售单 |
| 结构模板 | 五选一：九墩块四向进叉 / 三纵梁两向进叉 / 开槽纵梁四向进叉 / 滑木 / 胶合板；新建时按模板生成默认构件 |
| 使用范围 | 出口 / 内销，默认内销；只作展示与报告文案，不影响计算 |
| 进叉方向 | 四向 / 两向，默认四向；只作展示与报告文案 |
| 长度 / 宽度（mm） | 整数毫米，必填且 > 0；外形长宽 |
| 外形高度（mm） | = 全部构件高度之和，只读；改构件自动更新 |
| 目标载荷（kg） | 正整数，可空；本轮只展示，不参与校核 |
| 载荷形式 | 均布 / 集中，默认均布；本轮只展示，不参与校核 |
| 备注 | 手填，最多 500 字 |

### 结构模板

| 模板 | 默认构件 | 默认尺寸 |
| --- | --- | --- |
| 九墩块四向进叉 | 面板 5、中间纵梁板 3、墩块 9、底板 3 | 1200 × 800 |
| 三纵梁两向进叉 | 面板 7、纵梁 3、底板 3 | 1100 × 1100 |
| 开槽纵梁四向进叉 | 面板 7、开槽纵梁 3、底板 3 | 1100 × 1100 |
| 滑木 | 面板 7、滑木 3 | 1200 × 800 |
| 胶合板 | 胶合板面板 1、墩块 9、底板 3 | 1200 × 800 |

- 默认构件的名称、材料、方向、尺寸、数量以 `packages/shared/src/pallet.templates.ts` 为唯一实现，本表只登记结构关系。
- 新建项目时按模板生成构件；用户可增删构件、改尺寸与数量。
- 不提供模板管理、模板另存与外部模板导入。

### 编号规则

- 项目编号 `PD-00001`：租户内按前缀取最大流水 +1，唯一约束兜底并发，冲突重试。
- 删除项目 = 软删除，编号不回收。
- 全局格式见 `1-产品文档.md`「五、全局编号规范」；本域只登记前缀 `PD`。

### 页面设计

- **列表页**：筛选 = 项目名称 / 编号模糊、结构模板；列 = 编号、项目名称、客户名称、结构模板、外形尺寸、外形高度、木材体积、估算重量、更新时间；行操作 = 查看 / 编辑 / 复制 / 删除；新建按钮左置；分页。
- **新建页**：标题「新建托盘项目」；选结构模板后进入编辑器；保存成功后跳转项目详情 / 编辑页。
- **编辑器**：标题区与底部保存 / 取消固定，中间内容区独立滚动；左侧项目参数，右侧工程图与构件表；详情与编辑共用同一编辑器，只读角色隐藏保存。
- **复制**：深拷贝项目与全部构件，生成新编号，名称追加「副本」。
- **删除**：二次确认，软删除，编号不回收。

### 权限与功能

- 查看：`pallet:view`；新建 / 编辑 / 复制 / 删除：`pallet:manage`。
- 功能标识：`pallet_design`（可售模块，默认不进任何套餐）。

## R-托盘设计-002：构件编辑与木材料单

### 构件字段

| 字段 | 口径 |
| --- | --- |
| 层级 / 行序 | 构件从上层到下层的实际顺序；拖动调整后图纸与总高联动 |
| 构件类型 | 面板 / 端板 / 中间纵梁板 / 墩块 / 底板 / 纵梁 / 滑木 / 胶合板面板 / 垫块 / 自定义 |
| 名称 | 手填，默认取构件类型名；用于图纸标注与料单 |
| 材料 / 树种 | 从材料目录选择；v1 预置 11 种，只读，不支持增删改 |
| 方向 | 沿长度（x）/ 沿宽度（y）；决定构件在图纸中的摆放方向 |
| 长度 / 宽度 / 厚度（mm） | 整数毫米，必填且 > 0 |
| 数量 | 正整数，必填且 ≥ 1 |
| 损耗（%） | 0~100，默认 8；采购体积 = 净体积 ×（1 + 损耗） |
| 加工费（元/件） | ≥ 0，默认 0；按件计 |
| 单价覆盖（元/m³） | 0 表示使用材料目录单价；> 0 只覆盖本行材料单价 |

### 材料目录（v1 只读）

| 材料 | 密度 kg/m³ | 采购单价 元/m³ | 出口熏蒸 |
| --- | --- | --- | --- |
| 松木 | 500 | 1850 | 是 |
| 辐射松 | 500 | 2050 | 是 |
| 云杉 | 450 | 2150 | 是 |
| 杉木 | 420 | 1850 | 是 |
| 日本柳杉 | 380 | 2300 | 是 |
| 花旗松 | 530 | 2200 | 是 |
| 杨木 | 450 | 1550 | 是 |
| 桉木 | 650 | 1750 | 是 |
| 混合硬木 | 600 | 1550 | 是 |
| 胶合板 | 600 | 1850 | 否 |
| LVL | 550 | 2150 | 否 |

- 材料目录在租户首次读取时按上述默认值落库；v1 不提供材料新增 / 编辑 / 删除页面。
- 材料颜色按构件类型固定，不随材料变化；图纸配色用于区分构件角色。

### 计算口径

- 净体积（m³）= 长度 × 宽度 × 厚度 × 数量 ÷ 10⁹，按行保留 5 位小数。
- 采购体积（m³）= 净体积 ×（1 + 损耗），保留 5 位小数。
- 重量（kg）= 采购体积 × 密度，保留 1 位小数。
- 材料费（元）= 采购体积 × 单价（或单价覆盖），保留 2 位小数。
- 加工费（元）= 数量 × 加工费，保留 2 位小数。
- 项目合计 = 各行净体积 / 采购体积 / 重量 / 材料费 / 加工费分别求和。
- 金额与方量在服务端保存时重算，不信任前端提交的合计值；前端只用于即时预览。

### 结构基础校验

- 至少一个面板或胶合板面层；
- 至少一个墩块、纵梁或滑木支承；
- 九墩块模板至少 9 个墩块、3 块中间纵梁板，且中间纵梁板长度等于托盘宽度；
- 构件层级顺序为「面板 → 中间纵梁板 → 墩块 / 纵梁 → 底板」，异常顺序提示确认；
- 任一构件尺寸或数量 ≤ 0 时阻止保存；
- 总高 ≤ 0 时阻止保存。

校验只保证图纸与数据可继续使用，不代表承载合格。

### 页面设计

- **构件表**：列 = 层级、构件类型、名称、材料、方向、长、宽、厚、数量、损耗、加工费、单价覆盖、删除；支持上移 / 下移；行内编辑即时联动图纸与合计。
- **汇总条**：净体积、采购体积、估算重量、材料费、加工费。
- **校验区**：通过显示「基础结构检查通过」；异常逐条列出，并提示先修正再查看图纸。
- **材料目录**：只读下拉，不新开页面。

## R-托盘设计-003：2D 工程图

### 视图

- 三视图拼版：主视 + 侧视 + 俯视 + 轴测，2×2 布局。
- 单视图：俯视、主视、侧视、轴测。
- 视图切换不改变数据，只改变渲染。

### 绘图规则

- 俯视：按构件在长宽平面的位置绘制；低层构件半透明，上层不透明。
- 主视 / 侧视：按构件高度与前后位置绘制；前后遮挡按构件在另一水平轴的位置排序。
- 轴测：标准 30° 轴测投影；每个构件绘制可见侧面与顶面，按深度排序。
- 开槽纵梁在主视与轴测中绘制两个槽口轮廓，不用普通矩形代替。
- 构件颜色按构件类型固定；选中构件用高亮描边。
- 单视图标注外形长、宽 / 高；拼版不标注尺寸。
- 图纸上方显示外形尺寸、结构模板名、进叉方向、构件件数；下方显示叉孔净高与面板净跨。

### 页面设计

- 编辑器右侧为图纸区，顶部为视图分段按钮；图纸随构件表实时更新。
- 点击构件表行或图纸构件时，两侧同时高亮。
- 提供「导出 SVG 图纸」；导出内容与屏幕预览同源。

### 边界

- 不做尺寸链、公差、剖面图、局部放大、图框与标题栏。
- 图纸只表达几何结构，不表达承载等级。

## R-托盘设计-004：3D 视图与模型导出

### 3D 视图

- 正交相机，Z 轴向上；默认标准轴测角。
- 支持鼠标 / 触控旋转、滚轮缩放、右键平移；提供「复位视角」。
- 构件按类型着色并描边；点击构件与构件表双向联动。
- 3D 中只显示外形尺寸与选中构件尺寸；详细尺寸留在 2D 图纸。
- WebGL 不可用时自动回退到轴测图，并提示原因。

### 模型导出

- 导出 OBJ、STL；单位按 1 单位 = 1 mm。
- 开槽纵梁按实际槽口轮廓导出，不用简化矩形。
- STEP / DWG / SolidWorks 原生格式不在本轮，保留入口并提示需要 CAD 适配器。

### 页面设计

- 视图分段增加「3D」；首次进入时懒加载 3D 引擎，不拖慢首屏。
- 3D 区下方提供「导出 OBJ」「导出 STL」「复位视角」。

## R-托盘设计-005：工程图打印报告

### 入口与形态

- 编辑器操作区「打印报告」→ 打开报告页 `/admin/pallet-design/[id]/report`。
- 报告页为 A4 纵向打印版式；浏览器打印 / 另存 PDF；不做服务端 PDF。

### 版式与内容

- 抬头：固定「梅好木业」；标题「托盘结构图与木材料单」。
- 项目信息：项目编号、项目名称、客户名称、结构模板、外形尺寸、进叉方向、使用范围、备注。
- 图纸：轴测图 + 主视 / 侧视 / 俯视图。
- 木材料单：构件、材料、规格、数量、净体积、采购体积、重量占比。
- 汇总：净体积、采购体积、估算重量、材料费、加工费。
- 基础校验结果；固定声明「本报告用于方案沟通与备料参考，承载等级须按适用标准进行实物试验或工程复核」。
- 不打印 3D 截图、报价、税额、毛利。

### 页面设计

- 报告页只读；顶部提供「打印 / 另存 PDF」「返回编辑器」。
- 打印时隐藏导航、按钮与页面外壳；表格跨页重复表头，单行不跨页截断。
