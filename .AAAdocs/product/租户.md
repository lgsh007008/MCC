# 租户领域（tenant）

> 定位：租户领域的**需求**（What）。实现设计见 `design/租户.md`。
> 编号规则：`R-租户-NNN`
> 范围界定：租户档案、开通与启停、套餐与功能开关、账号额度。平台运营账号见 `product/账号与权限.md` R-账号与权限-004；平台运营跨租户审计见 `product/审计日志.md` R-审计-002。本领域为平台领域，与业务领域同等遵守同名配对、需求编号与页面归属唯一规则。
> 决策依据：`2-adr.md` ADR-012。

## R-租户-001：租户档案与开通

### 字段口径

| 字段 | 口径 |
| --- | --- |
| 租户编号 | 系统生成 `TN` + 5 位全局流水（如 `TN-00001`），只读、永不复用；同时作为登录标识，创建后不可改 |
| 租户名称 | 手填，必填，≤100 字；不建唯一约束，重名只提示不阻断 |
| 套餐 | 必选，只列启用套餐；开通时选择，后续可由运营改套餐 |
| 状态 | 启用 / 停用；新建默认启用 |
| 备注 | ≤500 字，可空 |
| 创建日期 | 系统写入，只读 |
| 首管理员账号 | 开通时必填；创建后归属该租户 `ADMIN` 角色；账号在租户内唯一；密码至少 8 位 |
| 账号数 / 额度 | 只读；账号数 = 该租户未删除账号数（含停用），平台运营账号不计入；额度取套餐 |

### 开通流程

1. 运营在「租户管理」新建租户：填写名称、套餐、备注，并设置首管理员账号与初始密码；
2. 系统先创建租户（编号自动生成），再在该租户内创建首管理员；
3. 两步任一步失败都停留在开通页并给出明确提示；租户已建但首管理员未建时，租户详情显示「未创建管理员」，可补建；补建成功前该租户无法登录；
4. 开通成功进入租户详情，不弹成功回执。

### 首个租户扶正

- 现有单租户数据整体归入首个租户：保留内部主键 `default`，登录编号取 `TN-00001`，名称「梅好木业」，套餐取默认套餐（包含当前全部可售模块）；
- 现有 `admin` 账号成为该租户的 `ADMIN`，历史数据不迁移、不改写；
- `default` 仅作为历史主键保留，不作为登录标识；新租户一律使用 `TN-#####`。

### 停用与启用

- **停用**：该租户全部账号立即不可登录；撤销该租户全部刷新令牌；访问令牌最多 15 分钟后自然失效；租户数据全部保留，可随时启用；
- **启用**：恢复登录；已撤销的刷新令牌不恢复，相关账号需重新登录；
- 停用需二次确认；启用为恢复性动作，直接执行；
- **不做删除**：租户不可删除，避免历史数据失去归属；不做租户数据导出。

### 页面设计

- **列表页**：见 R-租户-002。
- **开通表单页**（`/ops/tenants/new`）：独立表单页，不用弹窗——开通包含租户与首管理员两步、失败需在页内补建，不满足弹窗适用条件；字段 = 名称、套餐、备注、首管理员账号、初始密码；编号不展示（保存后系统生成）；保存 / 取消放固定操作区，错误提示在操作区上方。
- **详情页**（`/ops/tenants/[id]`）：标题 = 租户名称（编号括注）；信息条 = 编号、套餐、状态、账号数 / 额度、创建日期、备注；功能区 = 有效功能摘要（基础功能 + 可售功能）与「功能开关」入口；管理员账号区 = 该租户 `ADMIN` 账号列表（账号、状态）与「重置密码」行操作；操作区 = 编辑 / 改套餐 / 停用（启用）/ 返回列表；首管理员未建时，标题下显示提示与「补建管理员」按钮。管理员账号数据经 auth 公开接口取得，本页只引用、不重述账号规则。
- **编辑**：弹窗，字段 = 名称、备注；编号、套餐、状态不在编辑表单内（套餐走改套餐，状态走启停）。
- **改套餐**：弹窗，选择目标套餐，展示目标套餐的功能与额度变化；确认后即时生效；现有账号数超过目标额度时提示「现有账号数 X 超过目标额度 Y，将禁止新增账号」，不阻断变更。
- **功能开关**：弹窗，列出可售功能，每个功能显示「套餐包含 / 租户加购 / 租户关闭」三态；基础功能只读显示「始终启用」；保存后即时生效。

### 权限

- 查看：`platform:tenant:view`；
- 开通、编辑、启停、改套餐、功能开关、重置管理员密码：`platform:tenant:manage`。

## R-租户-002：租户列表与启停

### 列表

- 筛选 = 编号（模糊）、名称（模糊）、状态、套餐；
- 列 = 编号、名称、套餐、状态、账号数 / 额度、创建日期；
- 排序 = 创建日期（默认倒序，表头可切换正 / 倒序），其余列不排序；
- 行操作 = 查看 / 编辑 / 停用（启用）；改套餐与功能开关在详情页操作区，不放进列表行；
- **不做**首列多选与批量操作（本轮无批量动作，按列表页模式例外处理）；
- 分页默认 20 条；无数值汇总列，省略合计行；空态「暂无租户」。

### 账号数展示

- 显示「已用 X / 上限 Y」；X 为未删除账号数（含停用），Y 取套餐额度；
- 平台运营账号不计入任何租户；
- X > Y 时用警示色提示，并在新建租户账号时拦截（见 `product/账号与权限.md` R-账号与权限-002）；
- 账号数经 auth 公开接口取得，本领域不直读账号表、不建冗余列。

### 启停

- 停用二次确认，文案须写明：租户名称、该租户账号数量、停用后全部账号不可登录、数据保留、可随时启用；
- 启用直接执行，不弹确认；
- 启停结果即时生效，不等下一次登录。

## R-租户-003：套餐与功能开关

### 功能清单

| 功能标识 | 名称 | 类型 | 说明 |
| --- | --- | --- | --- |
| `account` | 账号与权限 | 基础 | 永远启用，不进套餐 |
| `platform` | 平台布局 | 基础 | 永远启用，不进套餐 |
| `tenant` | 租户自身 | 基础 | 永远启用；仅平台运营侧使用 |
| `order` | 订单 | 可售 | 销售单、打印、客户方量汇总 |
| `customer` | 客户 | 可售 | 客户档案 |
| `purchase` | 采购 | 可售 | 采购单 |
| `supplier` | 供应商 | 可售 | 供应商档案 |
| `production` | 生产与库存 | 可售 | 原木领用、方木产出、原木与方木库存、库存估值、盘点、每单材料毛利 |
| `finance` | 财务 | 可售 | 资金收付、应收应付、收支汇总 |
| `audit` | 审计 | 可售 | 租户内操作审计 |
| `packaging_design` | 包装设计 | 可售 | 包装方案与单元、托盘 / 木箱 / 围板 / 垫木 / 钢带箱、模板与材料库、2D / 3D 图纸、图纸集与导出、版本与发布 |

- 功能粒度按模块，不按页面；模块内新增页面自动继承该模块的功能开关；
- 移动端跟随所购模块，不单独作为可售功能；
- 新增可售模块时在本表登记功能标识，默认**不进任何套餐**，由运营决定加入哪个套餐；加入套餐即对该套餐下全部租户生效；
- 跨模块元素按其数据所属模块的 feature 裁剪：销售单详情的材料毛利卡由 `production` 控制，租户未购生产与库存时不展示、接口不返回材料毛利字段。

### 套餐

| 字段 | 口径 |
| --- | --- |
| 套餐名称 | 必填，唯一；不设业务编号 |
| 功能集合 | 从可售功能中选择；基础功能不参与配置 |
| 账号额度 | 非负整数；达到额度后禁止新增账号 |
| 状态 | 启用 / 停用；停用套餐不可被新租户选择，存量租户不受影响 |
| 备注 | 可空 |
| 创建日期 | 系统写入，只读 |

- 套餐不设价格、账期、试用期与计费字段；改套餐为运营直接操作，不做审批、差价结算与升降级流程；
- 套餐不可删除，只可停用。

### 有效功能

- 有效功能 = 套餐功能 ∪ 租户加购 − 租户关闭；
- 租户覆盖只存与套餐不同的项，不复制套餐全量；
- 基础功能永远有效，不可关闭；
- 功能关闭后：业务接口返回 `FEATURE_DISABLED`，前端菜单与入口隐藏；历史数据保留，重新开启即恢复；
- 套餐或覆盖变更后即时生效，无需租户重新登录；前端在下一次会话恢复或页面刷新后同步菜单。

### 降套餐

- 允许运营直接改为更小套餐；
- 现有账号数超过目标额度时，不强制停用现有账号，但禁止新增账号，直至账号数降到额度内；
- 降套餐不删除任何数据；被移除的功能按功能关闭口径处理。

### 页面设计

- **套餐列表**（`/ops/plans`）：列 = 套餐名称、功能数、账号额度、状态、创建日期；行操作 = 编辑 / 停用（启用）；无多选与批量操作；新建 / 编辑用弹窗（字段 = 名称、功能多选、账号额度、备注，无明细，≤6 项），保存后关闭并刷新；不做删除。
- **租户功能开关**：见 R-租户-001 详情页的「功能开关」弹窗；三态展示，保存即时生效。
- 套餐页面归属本领域；`/ops` 壳归 `platform`，本领域只登记菜单项与页面内容。

### 权限

- 查看：`platform:tenant:view`；
- 套餐新建 / 编辑 / 启停、租户功能开关：`platform:tenant:manage`。

### 边界

- 不做在线计费与支付、试用期、续费、按量计费、审批与差价结算；
- 不做白标、自定义域名与租户数据导出；
- 不做租户自定义角色（租户内四角色固定，见 `product/账号与权限.md` R-账号与权限-003）。
