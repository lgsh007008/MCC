# 落地页领域（landing）

> 定位：落地页领域的**需求**（What）。实现设计见 `design/落地页.md`。
> 编号规则：`R-落地页-NNN`
> 范围界定：对外公开的单页落地页、互动演示与注册转化；不含登录后的 `/admin`、`/m`，也不含平台运营 `/ops`。页面归属唯一：`/` 归本领域；包装方案库与工作台仍归 `packaging`。
> 品牌说明：当前对外沿用「梅好木业」，属临时品牌；换名时按 `design/落地页.md` 的品牌文案清单全局替换，不抽品牌常量。
> 输入资产：`mock/` 与 `参考/` 中的原型 / 竞品页面只作设计输入，不进入本文档体系，也不嵌入页面。

## R-落地页-001：公开落地页

**路由与入口**：`/`，无需登录；`/login`、`/register` 保持独立。登录成功后 PC 进入 `/admin/packaging-design`、移动 Web 进入 `/m`；注册成功后 PC 进入 `/admin`、移动 Web 进入 `/m`（现状，不在本次调整）。落地页不套 `/admin`、`/m`、`/ops` 任一壳，不进入租户菜单。

**页面结构（单页）**：

1. 顶部：白色悬浮导航，品牌名（当前「梅好木业」）、锚点（能力 / 流程 / 在线体验）与「登录」入口；
2. 首屏：浅色两栏 + 价值主张 + 主 CTA；右侧白卡内是**深色 3D 画布**（自动旋转、模板胶囊当场切换、外形尺寸标注），深色只作为这一处画布的重点，不铺满整屏；
3. 滚动叙事：桌面为 sticky 舞台，随滚动依次呈现「结构 → 三视图 → 料单」；手机逐条展开；
4. 在线工作台：见 R-002，含模板画廊、迷你工作台与全屏体验；
5. 能力区：参数化 2D / 3D、构件与 BOM / 开料、图纸与打印报告、方案版本与复制，只讲当前真实能力；
6. 结尾 CTA 与页脚：品牌与会话入口；备案号、联系方式在实际域名上线后补充，条款 / 隐私按需后续补充。

**CTA**：主 CTA「免费注册」→ `/register`；「登录」→ `/login`；首屏另设「进入在线工作台」锚点到本页 `#workbench`；不另设定价页、预约表单或多级页面，所有区块锚点留在本页内。

**品牌与文案**：当前名与副标题按字面量书写，不抽常量；换名时按设计文档的品牌文案清单逐项替换。

**边界**：不做多页官网、博客、案例库、定价页；不搬完整工作台；不做多品类包装工作台；不嵌入 3.6MB 原型 HTML；不展示未上线的功能承诺。

## R-落地页-002：在线工作台与 3D 演示

**演示范围**：第一版只做托盘，五种结构模板可在页内切换；不做木箱、围板、垫木、钢带箱。参数 = 长、宽、模板；实时输出 = 外形尺寸、净体积、重量、构件数与构件清单。演示明确标注「简化演示，注册后使用完整工作台」。

**三层演示**：

1. **首屏舞台**：模板胶囊切换结构，缓慢自动旋转，外形尺寸以标注线浮在画布上；桌面可直接拖拽；
2. **模板画廊**：五种结构以缩略轴测图并排展示，点击后把结构带入下方迷你工作台；
3. **迷你工作台**：桌面为「左模板 / 中舞台 / 右参数 / 下构件清单」四区；手机顺序堆叠。支持 2D / 3D 切换、长宽滑杆与「全屏体验」；
4. **全屏体验**：桌面与手机均可打开全屏工作台，保留模板、参数、3D 与构件清单；ESC 或关闭按钮退出，退出后参数保持一致。

**交互**：

- 参数或模板变化即时重算，2D 轴测、3D、结果数字与构件清单同步；
- 桌面：舞台进入视口后自动加载 3D 并缓慢自动旋转；离开视口停止旋转，避免无意义渲染；
- 手机：先显示静态轴测与「看 3D」，点击后加载；不自动起 3D；
- 3D 支持拖拽旋转、缩放、复位；不提供构件选中、编辑、保存、导出、打印；
- 全屏体验只放大同一份演示，不新增页面、不写地址栏状态；
- WebGL 不可用时回退 2D 轴测并提示。

**数据与边界**：纯前端，不调用租户接口、不落库、不产生审计；演示数据与共享几何同源，保证与真实工作台口径一致。演示不构成方案，不生成 `PD` 编号；全屏关闭后不保留任何服务端状态。

## R-落地页-003：移动端与性能

**移动端**：一个 `/` 响应式页面，断点沿用 767px；手机编排为「压缩首屏 → 在线工作台 → 能力 2×2 → 三步 → 页脚」，滚动叙事改为逐条展开；底部固定「免费注册」条，滚到页尾 CTA 时隐藏；触控目标 ≥44px；页面不出现横向滚动；兼容微信内置浏览器（不依赖 WebGL、不触发文件下载）。

**性能与 SEO**：首屏不加载 three.js 组件本体，舞台进入视口后再动态加载；同页最多两个 3D 舞台（首屏 + 工作台），离开视口的舞台停止自动旋转；静态预览用 SVG；系统字体或子集；4G 下 LCP 目标 2.5s 内；提供 `metadata`（标题、描述、OG），品牌文案与页头一致。

**动效与可访问性**：滚动揭示、悬浮与舞台动效只用 CSS 过渡 / 关键帧与 IntersectionObserver，不引入动画库；`prefers-reduced-motion: reduce` 时关闭自动旋转、位移动画与滚动揭示的初始位移，内容直接可见；键盘可操作全部按钮与滑杆。

**转化**：注册仍走 `/register`，成功后按视口进入 `/m` 或 `/admin/packaging-design`；第一版不带演示参数，后续可扩展。

**边界**：不做 `m.` 子域、不做 UA 跳转、不占用 `/m`；不为移动端单独维护第二套页面。

## R-落地页-004：视觉基线与登录页共用

**视觉方向**：全浅色，白 / 浅灰为底，品牌绿只用于主按钮、链接、眉标与选中态，**不使用主色大面积铺底**；页面唯一允许的深色是 3D 画布本身，且画布包在白卡内，不形成整屏深色。静态容器以边框、留白和字重区分层级，不使用装饰性阴影；整体遵循 `product/平台布局.md` 的「纯白 + 强结构、品牌绿为唯一强调色」基线。

**登录 / 注册共用**：`/login` 与 `/register` 共用同一认证页外壳与托盘舞台。桌面为左右分栏：左侧表单，右侧浅灰面板内放深色 3D 画布；手机表单优先，上方只保留压缩品牌条与静态轴测海报，不加载 3D。登录字段、校验、记住登录、注册企业入口与成功后分流均不变；注册字段、`registerSchema` 校验与成功后分流同样不变。

**动效基线**：首屏文字与按钮入场、舞台缓慢旋转、滚动揭示、卡片悬停与按钮按压；动效服务于层级与反馈，不循环闪烁、不阻塞操作；遵守系统「减少动态效果」设置。

**边界**：不改登录鉴权与接口；不引入动画库、外部大图或视频；不做深浅色主题切换；不改变 `/m` 与后台视觉。
