# 包装设计领域（packaging）

> 定位：包装设计领域的**需求**（What）。实现设计见 `design/包装设计.md`。
> 编号规则：现行需求 `R-包装设计-NNN`；历史编号 `R-托盘设计-001~005` 已归档到文末附录，停用、不复用。
> 范围界定：以「方案」为单位设计出口包装，方案包含托盘、普通木箱、滑木箱、框架箱、围板、垫木、钢带箱等单元；每个单元由构件组成，输出 2D 工程图、3D 视图、图纸集、木材料单、开料与打印报告。力学承载校核、真 FEM、通用 CAD、STEP、移动端与外部结构导入不在本轮。

---

## 产品目标与主流程

- 产品目标：把出口包装方案从「手工摆构件」收敛为「选结构 → 定配置 → 看派生」；用户只改少量参数，3D、三视图、图纸与料单立即给出同一结果。
- 主流程：选择单元类型与结构模板 → 填内尺寸、载荷与骨架参数 → 调结构配置（铺板、框架、支承、进叉）→ 系统派生外尺寸与构件 → 按需微调构件 → 校验 → 出图 / 料单 / 报告 → 保存 / 发布。
- 三条原则：
  1. **结构、配置、派生分层**：结构决定几何关系，配置是用户可调参数，派生是二者的计算结果；视图、图纸与料单只消费派生结果。
  2. **参数优先、覆盖兜底**：默认构件由参数自动生成；手工修改作为覆盖保留，参数变化时按 R-包装设计-016 的规则重算。
  3. **筛查级规则**：载重、尺寸与结构只做可制造性 / 可用性筛查，不做强度计算，不承诺承载合格。
- 本轮主线：规则优先的参数化内核；FEA、自动优化与 CAD 内核不在范围。

## 定位与竞品参照

- 参照 **CratePilot**：借鉴「改参数立即看到 3D」的实时反馈与参数分组；不借鉴静默夹取上限、超限不提示等交互。
- 参照 **托盘行业工具 v3.5**：借鉴结构模板、铺板数量与料单口径；不复制代码、文案、图标与演示数据。
- 参照 **颂林包装图纸软件**：借鉴图纸集与打印报告的交付形态；不做通用 CAD 与自由绘图。
- MCC 的差异：以「方案 → 单元 → 构件」为数据模型，文档驱动开发，规则与派生同源；所有视图、图纸、BOM 与报告由同一份派生结果生成。

## 领域模型

| 概念 | 口径 |
| --- | --- |
| 方案 | 一套包装的商业与工程分组，编号 `PD-#####`；结构上可含 1..n 个单元，工作台按 1:1 编辑与保存 |
| 单元 | 方案内的物理件，类型见下表；有独立外形尺寸、模板与构件；工作台一次只编辑并保存一个当前单元 |
| 构件 | 单元内的零件；材料、规格、数量、损耗、加工费 |
| 模板 | 单元类型的配置与派生规则；优先数据驱动，需要专属几何时由共享构建器实现 |
| 版本 | 方案发布时的不可变快照；旧版本不随材料价与模板变化 |
| 图号 | 方案 `PD-00001`、单元 `PD-00001-U01`、图纸 `PD-00001-U01-01` |
| 结构 | 单元的类型与几何关系（底座 / 箱体 / 箱盖、面板 / 纵梁 / 墩块等），由单元类型与模板决定，用户不直接编辑 |
| 配置 | 用户可调参数（内尺寸、板厚、框架、支承、铺板数量、进叉方向等），存 `params`；只存本机草稿的覆盖标记不计入配置持久化 |
| 派生 | 由结构与配置计算出的外尺寸、构件表、几何、BOM、图纸与校验结果；不作为独立数据源 |

- 三层关系：结构 = 代码构建器；配置 = `params`；派生 = 纯函数。手工修改构件只作为覆盖，不改变结构定义；视图与料单不得自行推导另一套结果。

- 单元类型是封闭枚举；新增类型改文档与代码，新增模板只加数据。单元类型与模板由左栏目录选中项决定，不提供独立类型切换。
- 客户名称只作文本快照，不建客户外键、不生成销售单。

## R-包装设计-006：包装方案与单元管理

### 方案字段

| 字段 | 口径 |
| --- | --- |
| 方案编号 | 系统生成（`PD` + 连字符 + 5 位流水，如 `PD-00001`），只读、永不复用 |
| 方案名称 | 手填，必填，最多 100 字；新建时默认「未命名方案」；顶栏内联编辑 |
| 客户名称 | 手填，可空，最多 100 字；只作展示，不建客户外键、不生成销售单 |
| 使用范围 | 出口 / 内销，默认出口；只作展示与报告文案 |
| 状态 | 草稿 / 已发布 / 已归档；新建默认草稿；已发布与已归档只读 |
| 备注 | 手填，最多 500 字 |
| 合计 | 合计 = 当前单元合计（体积、重量、材料费、加工费、报价）；不单独聚合方案；服务端保存时重算 |

### 单元字段

| 字段 | 口径 |
| --- | --- |
| 单元类型 | 由左栏单元目录选中项决定；首次保存后固定，不可跨类型切换 |
| 单元名称 | 默认取模板名或尺寸 + 模板名；工作台不提供编辑 |
| 模板 | 从单元目录或参数区选择；决定参数与默认构件；首次保存后同类型内仍可在草稿更换（需确认），发布 / 归档后锁定 |
| 长 / 宽 / 高（mm） | 整数毫米，必填且 > 0；由结构配置派生，工作台只读展示；木箱外尺寸含板厚、框架、底板与底部支承 |
| 目标载荷（kg） | 正整数，可空；参与筛查级构件推导与结论分级，不做强度校核 |
| 载荷形式 | 均布 / 集中，默认均布；参与筛查级提示，不做强度校核 |
| 类型参数 | 按模板定义，如进叉方向、箱型、板厚、铺板数量；存 `params`；结构配置见 R-包装设计-015 |
| 数量 | 工作台固定 1 个当前单元；保存只提交当前单元 |

### 页面设计

- **方案库（列表页）**：筛选 = 方案名称 / 编号模糊、单元类型、状态；筛选下方左侧「新建包装方案」；卡片画廊展示单元轴测缩略图、状态徽标、方案名称、客户、单元类型与尺寸、体积 / 重量、更新时间，方案编号弱化在页脚；页脚常驻「进入设计 →」，整卡进入工作台；复制 / 删除为 hover 图标；分页。方案库只做方案管理与检索，不承载设计编辑。
- **新建工作台**：方案库点「新建方案」直接进入 `/admin/packaging-design/new` 空白工作台，不预先弹窗、不落库；新建时方案名称默认「未命名方案」。进入后画布顶部是「可用包装结构」区块头，右侧提示「在左侧目录选择类型开始设计」，下方是七类单元轴测预览；左侧目录列出七个单元类型与模板；未选择结构前不展示默认单元，保存 / 发布 / 打印 / 导出禁用，右 / 底工具条不可用；从目录选择结构后进入画布与参数。首次保存后单元类型固定，草稿内可更换同类型模板。
- **首次保存**：工作台点保存 / Ctrl+S 弹出轻量弹窗，只填方案名称（必填）与客户名称（可选）；名称默认取顶栏当前值；提交后创建方案、生成 `PD` 编号并替换为正式方案路由；后续保存直接保存，不再弹窗。选择结构后、未保存时发布与打印报告禁用，SVG / DXF / CSV 导出可用；使用范围默认出口，使用范围、备注在右侧「方案」标签。
- **工作台（编辑器）**：全屏三列。左栏通高，是「单元目录树 ↔ 单元参数」：目录父级 = 七个单元分类，子级 = 该分类的模板 / 单元；选中一个即成为当前方案单元；不提供 + 托盘 / + 木箱、上移 / 下移、复制单元、删除单元。参数态顶部用左向 chevron 返回目录；左栏靠画布内侧边缘设竖向双箭头把手（16×40，垂直居中），收起后 48px 竖条保留反向把手与竖排「单元参数」；左栏不使用卡片，小节用标题 + 1px 分隔线，去掉说明文案。顶部文档栏只覆盖主内容区 = 方案名称（内联输入，点击即改）、状态、保存状态（已保存 / 未保存 / 保存中）、版本徽标；右侧依次为「撤销 / 重做」图标按钮（无可用历史时禁用）、发布、打印、保存、导出。撤销 / 重做同时支持 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z；导出是工作台唯一的文件导出入口，清单见 R-包装设计-008；不再放返回、方案号与视图切换。中央画布见 R-包装设计-014；右侧工具面板与底部面板见下两条。
- **右侧工具面板**：固定 4 个 icon + 文案标签「方案 / 构件 / 校验 / 版本」，无 ×；打开后工具条隐藏，切换只点标签；默认 320px，可拖宽 280–520；靠画布内侧边缘的竖向双箭头把手收起，回到工具条，并记住上次工具；tab 栏不放面板图标按钮；版本列表从底部移入右栏。方案标签只放客户名称、使用范围、备注与当前单元合计；方案名称已移到顶栏，右侧不再重复。校验标签顶部显示 R-包装设计-017 的结论卡（等级、单位面积载荷、原因与免责声明）。右栏不设快捷键入口。
- **底部面板**：固定 3 个 icon + 文案标签「构件表 / BOM / 开料」，无 ×；关闭态是画布内的横向图标卡（三个图标，暂不显示数量徽标，恢复时与右侧同规则）；打开后图标卡隐藏，切换只点标签；上沿中央设横向双箭头把手：点击收起，按住拖动调整高度；收起回到三图标卡；版本不在底部。底部只占主内容区，不跨左右栏。
- **画布**：视图栏承载 2D / 3D / 图纸 / 分屏与 2D 方向（三视图 / 俯视 / 主视 / 侧视 / 轴测）；缩放与尺寸信息为文字控件，缩放组为「− / + / 复位」，复位回到默认取景；2D 画布内不显示视图名称，方向只由视图栏表达，右下角显示「左键拖拽平移 · 滚轮缩放 · 点击构件选中」；选中构件与构件表 / 右侧构件面板双向联动；四种视图共用同一画布框（12px 内边距 + 1px 边框）：2D 在框内再留 24px 且不画分幅边框，3D 铺满，图纸按宽适配、屏幕预览隐藏图框，分屏在同一框内用 1px 分隔线分左右；2D 与 3D 都支持按钮与滚轮缩放，3D 复位同时恢复视角与缩放，分屏只保留「复位」并同时复位 2D 与 3D。
- **目录**：页头标题「目录」；父级按单元类型分组，每类使用结构缩略图标（与平台菜单图标区分），行可折叠展开（默认全部展开），不显示数量；子级列出该类型的模板，只显示模板名，不显示规格与编号；选中子级即切换当前单元并进入参数，选中项右侧显示「当前」，非选中项 hover 显示带横线箭头；参数态返回用同款反向箭头；首次保存后单元类型固定，`DRAFT` 草稿可在同类型内更换模板；发布 / 归档后结构完全锁定，目录中其他项不可再切换。保存只提交当前单元；方案合计取当前单元合计；切换单元时图纸、构件表与右侧面板联动。
- **参数分组**：左栏参数按「基本参数 / 外形或箱体尺寸 / 铺板配置 / 载荷」分组；工作台只用 12 / 13 两档字号——区块标题 13px 带品牌色竖线，字段标签 12px，输入 / 值 13px，提示 12px；数值输入 150ms 防抖，停顿后再重算，避免逐位输入反复重建构件；派生外尺寸与构件数量只读展示，修改入口在参数区。
- **只读**：已发布（`ISSUED`）与已归档（`ARCHIVED`）均为只读；可导出、打印、复制方案，不能设计、保存、发布。发布要求已保存、无未保存变更、未发布且当前单元无阻断校验；发布生成快照、清除本机草稿并刷新版本列表。已发布方案提供「新建下一版本」；版本列表提供详情与按版本打印（见 R-包装设计-010）。
- **文档状态**：未保存变更显示脏标记；自动草稿只存本机浏览器（按用户 + 方案 / 新建标签页隔离，800ms 防抖），只恢复设计数据，不恢复选中单元 / 左栏视图 / 面板开合 / 撤销栈；保存、发布或丢弃后清除；只读方案不写草稿；支持文档级撤销 / 重做（最多 50 步、700ms 合并，不持久化、不覆盖视图状态），并提供顶栏按钮与快捷键；成功 / 信息反馈为画布顶部居中 Toast，约 2.5s 自动消失，错误提示常驻。
- **窄屏**：工作台为桌面全屏布局；窄屏折叠左栏，右侧面板保持列；不提供移动端设计页。
- **背景与视觉**：不再给工作台做平台壳颜色特例；平台侧栏与标签栏在所有页面使用同一套平台令牌。工作台左栏与顶栏同背景（`bg-background`，白色），平台侧栏保持 `bg-sidebar` 灰色；顶栏 / 画布 / 右栏 / 底栏白；进入工作台时平台侧栏自动折叠为图标栏（可手动展开）。打开态面板是停靠列 / 区域，只有关闭态工具条卡与底部图标卡是浮卡。工作台使用专用紧凑字阶（标题 15、正文 / 输入 13、标签 12、Tab 12.5、表格 11.5 / 12.5、行高 34–36）；绿色只保留在保存按钮、激活下划线与焦点环。工作台左 / 右 / 底局部面板统一用「边缘 + 双箭头」把手：左栏贴右边缘、右栏贴左边缘、底栏贴上沿中央，16×40 / 40×16，默认浅色底 + 1px 边框 + 轻阴影、hover 底色加深并显示 tooltip、不写文字，180–220ms 动画；平台侧栏折叠仍用底部全宽行（双箭头 + 收起 / 展开文字，整行可点；折叠态文字隐藏），两者区分；左栏目录↔参数切换用 chevron 对 + 淡入 / 横移动画。
- **复制**：深拷贝方案、当前单元与构件，生成新编号，名称追加「副本」；无论源方案是草稿还是已发布，复制结果一律为草稿。
- **删除**：二次确认，软删除，编号不回收。
- **测试数据**：存量 e2e 多单元方案不再保留；工作台只按当前单元读取，历史多单元数据不作为产品数据迁移。

- 功能标识：`packaging_design`（可售模块，默认不进任何套餐）。

## R-包装设计-007：普通木箱（CRATE）参数化设计

> 本需求描述 `CRATE` 单元；首切片为 G 型。结构固定为「底座 + 箱体 + 箱盖」，用户只调配置，不自由增删结构构件。

### 参数

| 字段 | 口径 |
| --- | --- |
| 内长 / 内宽 / 内高（mm） | 整数，必填且 > 0；决定内装物空间 |
| 面板厚（mm） | 整数，默认 15；侧板、端板、盖板共用 |
| 底板厚（mm） | 整数，默认 15；与面板厚分离 |
| 底部支承高度（mm） | 整数，默认 90；滑木高度，决定叉孔与离地高度 |
| 框架厚度（mm） | 整数，默认 90；立柱截面宽，参与外尺寸推导 |
| 结构形式 | G 型：底座 + 箱体 + 箱盖；本切片只做 G 型 |
| 材料 | 面板 / 框架 / 底座分别从材料目录选择 |
| 熏蒸要求 | 出口默认是；只影响报告文案与材料筛选提示 |
| 钢带 | 可空；按箱体周长与位置生成构件；钢带详图待确认（见 R-包装设计-008） |
| 钢带数量（道） | 0–4，默认 2；0 表示不配钢带；存 `params.steelStrapCount` |
| 进叉方向 | 四向 / 两向，默认四向；用于图纸与报告标注，不改变几何 |

### 外尺寸派生

- 外长 = 内长 + 2 ×（面板厚 + 框架厚度）
- 外宽 = 内宽 + 2 ×（面板厚 + 框架厚度）
- 外高 = 内高 + 底板厚 + 盖板厚（= 面板厚）+ 底部支承高度
- 外尺寸只读展示；参数变化时按 R-包装设计-016 重算构件与几何。

### 默认构件

| 部位 | 默认构件 | 规格口径 |
| --- | --- | --- |
| 底座 | 滑木 3、底板 1 | 滑木：外长 × 90 × 支承高度；底板：外长 × 外宽 × 底板厚 |
| 箱体 | 侧板 2、端板 2、立柱 4 | 侧板：内长 × 面板厚 × 内高；端板：（内宽 + 2 × 面板厚）× 面板厚 × 内高（端板包住侧板）；立柱：框架 × 框架 × 内高 |
| 箱盖 | 盖板 1 | 外长 × 外宽 × 面板厚 |
| 加固 | 钢带 2（可配 0–4） | 按箱体周长生成；护角未预置 |

- 默认构件以 `packages/shared/src/design/crate.ts` 的 `deriveCrateParts` 为唯一实现；`crate-g` 模板只保留参数定义，不再重复构件行。
- 构件表允许改材料、尺寸、数量与费用，作为**覆盖**；不再提供自由增删结构构件。

### 计算与校验

- 净体积、采购体积、重量、材料费、加工费口径见 R-包装设计-013。
- 至少一个底座承重构件；四周封闭；盖板覆盖内空；任一构件尺寸或数量 ≤ 0 阻止保存。
- 外尺寸小于派生值（内尺寸 + 板厚 + 框架）时阻止保存。
- 校验只保证图纸与数据可继续使用，不代表承载合格。

### 页面设计

- 复用方案工作台：左栏参数区按「基本参数 / 箱体尺寸 / 加固 / 载荷」分组，公布内长、内宽、内高、面板厚、底板厚、底部支承、框架厚度、进叉方向与钢带数量；外尺寸只读。
- 构件表与 2D / 3D 随参数实时更新；图纸支持木箱三视图与轴测（视图规则见 R-包装设计-014）；木箱展开图待确认（见 R-包装设计-008）；3D 显示底座、箱体、盖板与钢带。

## R-包装设计-013：构件与料单通用规则

> 本需求适用于所有单元类型（`PALLET`、`CRATE` 及后续单元）；托盘与木箱不再各自定义料单口径。

### 构件字段

| 字段 | 口径 |
| --- | --- |
| 层级 / 行序 | 构件从上层到下层的实际顺序；上移 / 下移后图纸与总高联动 |
| 构件类型 | 面板 / 端板 / 中间纵梁板 / 墩块 / 底板 / 纵梁 / 滑木 / 胶合板面板 / 垫块 / 箱板 / 框架 / 木条 / 钢带 / 垫木 / 自定义 |
| 名称 | 手填，默认取构件类型名；用于图纸标注与料单 |
| 材料 / 树种 | 从材料目录选择；目录见 R-包装设计-009 |
| 方向 | 沿长度（x）/ 沿宽度（y） |
| 长度 / 宽度 / 厚度（mm） | 整数毫米，必填且 > 0 |
| 数量 | 正整数，必填且 ≥ 1 |
| 损耗（%） | 0~100，默认 8；采购体积 = 净体积 ×（1 + 损耗） |
| 加工费（元/件） | ≥ 0，默认 0；按件计 |
| 单价覆盖（元/m³） | 0 表示使用材料目录单价；> 0 只覆盖本行 |
| 来源 | 自动（由参数派生）/ 手动（用户覆盖）；由派生默认值与当前构件的差异计算，不单独存储 |
| 覆盖依据 | 自动行显示派生依据（模板 / 参数）；手动行记录覆盖字段（尺寸 / 数量 / 材料 / 费用） |

### 计算口径

- 净体积（m³）= 长 × 宽 × 厚 × 数量 ÷ 10⁹，保留 5 位小数。
- 采购体积（m³）= 净体积 ×（1 + 损耗），保留 5 位小数。
- 重量（kg）= 采购体积 × 密度，保留 1 位小数。
- 材料费（元）= 采购体积 × 单价（或单价覆盖），保留 2 位小数。
- 加工费（元）= 数量 × 加工费，保留 2 位小数。
- 合计 = 各行分别求和；服务端保存时重算，不信任前端合计。
- 净耗与含损分列展示：下料与采购看含损，体积对比看净耗。

### 校验分级

| 级别 | 含义 | 行为 |
| --- | --- | --- |
| 错误 | 数据不可继续（零尺寸、无面层、无支承、外尺寸小于派生值等） | 阻止保存 / 发布 |
| 提示 | 结构非常规或可能影响工艺（开槽纵梁缺失、层级顺序异常等） | 允许继续，需用户确认 |
| 信息 | 筛查级结论与建议（载重与构件是否匹配、铺板数量偏离模板等） | 只展示，不阻断 |

- 至少一个面板或胶合板面层；
- 至少一个墩块、纵梁、滑木或框架支承；
- 任一构件尺寸或数量 ≤ 0 时阻止保存；
- 总高 ≤ 0 时阻止保存；
- 开槽纵梁模板缺少开槽纵梁时提示确认，图纸按普通纵梁绘制。

校验只保证图纸与数据可继续使用，不代表承载合格。

## R-包装设计-016：派生与重算规则

### 触发条件

| 触发 | 结果 |
| --- | --- |
| 改内尺寸 / 板厚 / 底板厚 / 框架 / 支承 | 重算木箱外尺寸、全部构件与几何 |
| 改托盘长 / 宽 | 重算模板构件；自动铺板取新尺寸下的模板值，手动铺板保留数量 |
| 改铺板模式 / 数量 | 只重算对应铺板数量；不重建其他构件 |
| 改模板 / 单元类型 | 按新模板重建构件与配置默认值 |
| 手工改构件 | 只改该行，并标记为手动覆盖；不重算其他行 |

### 规则

- 派生顺序：先结构，再配置，再派生，最后应用覆盖；不得在视图层另行推导。
- 同一输入必须得到同一输出（幂等）；2D、3D、图纸、BOM 与报告消费同一份派生结果。
- 数值输入 150ms 防抖：连续键入只在停顿后重算一次；失焦立即提交。
- 参数重算会重建自动行；手动覆盖行在可保留时保留（材料、损耗与费用按角色 + 名称继承，尺寸与数量回到派生值）；无法保留时（如模板切换）回到新模板派生值。
- 手动修改面板 / 底板数量视同切换该铺板为手动模式；切回自动时恢复模板默认数量。
- 外尺寸不持久化为独立设计输入：木箱由配置派生；托盘长宽即外形输入，外形高度由构件汇总。
- 配置随 `params` 保存与恢复：重新打开方案时优先读 `params.deck` / 钢带数量；只有旧数据缺少配置时，才用构件数量与模板默认值反推。
- 构件来源由派生默认值与当前构件逐字段比较得出：完全一致为「自动」，任一尺寸、数量、材料、方向、损耗或费用不同为「手动」；手动铺板模式本身也标记为「手动」。
- 来源标记只用于展示与解释，不参与计算；BOM、构件表与报告使用同一份比较结果。

## R-包装设计-017：项目筛查与结论分级（阶段三）

> 本需求为筛查级规则，不做强度计算；阶段三实现结论函数、工作台结论卡与报告结论区。

### 输入与计算

- 输入：目标载荷、载荷形式、底面积、当前单元校验问题。
- 底面积：托盘取 `长度 × 宽度`；木箱取 `内长 × 内宽`，统一换算为 m²。
- 单位底面积载荷 = 目标载荷（kg）÷ 底面积（m²），保留 1 位小数展示。

### 结论分级

| 结论 | 判定 | 展示 |
| --- | --- | --- |
| 优良 | 单位底面积载荷 ≤ 500 kg/m²，且无错误 / 提示级校验，载荷形式为均布 | 绿色结论 + 关键尺寸与构件摘要 |
| 可用 | 单位底面积载荷 500–800 kg/m²；或载荷 ≤ 500 但存在提示 / 集中载荷；或载荷为空但结构完整 | 中性结论 + 需确认项 |
| 需调整 | 单位底面积载荷 > 800 kg/m²；或存在错误级校验；或底面积无效 | 警示结论 + 调整建议 |

判定顺序：

1. 存在错误级校验 → 需调整，原因优先列错误；
2. 底面积 ≤ 0 → 需调整，提示「底面积无效」；
3. 目标载荷为空 → 可用（未评估），不记优良；
4. 载荷 > 800 → 需调整；500–800 → 可用；≤ 500 → 优良；
5. 存在提示级校验或载荷形式为集中 → 优良降为可用，并列出原因；集中载荷提示「需确认支承位置与局部加固」。

### 展示与边界

- 工作台右栏「校验」顶部显示结论卡：等级、单位面积载荷、底面积、目标载荷、原因列表。
- 报告每个单元显示结论区；报告首页或末页显示固定免责声明。
- 结论不阻断保存 / 发布；错误级校验仍按现有规则阻断。
- 阈值是本轮筛查基线，不是承载额定值；后续如需工程化，另立需求并给出计算书。
- 固定免责声明：「筛查级结果，不代表承载合格」。

## R-包装设计-022：垫木（DUNNAGE）

> 阶段四；状态：已确认·已实现（2026-11-18）。垫木是支撑 / 隔离 / 加固用的梁件，没有箱体与围挡。

### 结构与参数

- 结构：一组平行或交叉垫木；平行时单层，交叉时上下两层。
- 模板 code `dunnage-g`。

| 参数 | 口径 |
| --- | --- |
| 长度（mm） | 单根长度，必填且 > 0 |
| 宽度（mm） | 单根宽度，默认 90 |
| 厚度（mm） | 单根厚度，默认 90 |
| 数量 | 1–20，默认 3 |
| 排列 | 平行 / 交叉，默认平行 |
| 间距 | 自动均分，可只读展示 |

### 外尺寸与构件

- 平行：外形 = 长度 ×（数量 × 宽度） × 厚度；构件为 N 根。
- 交叉：外形 = 长度 × 宽度 ×（2 × 厚度）；构件为上下两组，每组按数量均分。
- 数量或排列变化时重算构件与几何。

### 校验与页面

- 数量 ≥ 1；长 / 宽 / 厚 > 0；交叉排列时至少 2 根。
- 左栏参数分组：基本参数 / 尺寸与排列 / 载荷；外尺寸只读。
- 3D 与三视图显示梁件排布；报告只出料单与简图，不标承载。

## R-包装设计-023：钢带箱（STEEL_STRAP）

> 阶段四；状态：已确认·已实现（2026-11-18）。钢带是主要加固手段，区别于普通木箱的可选钢带。

### 结构与参数

- 结构：胶合板箱体 + 可选木框架 + 滑木底座 + 盖板 + 钢带；钢带按横向或纵横布置。
- 模板 code `steel-strap-g`。

| 参数 | 口径 |
| --- | --- |
| 内长 / 内宽 / 内高（mm） | 整数，必填且 > 0 |
| 面板厚 / 底板厚（mm） | 默认 15 / 15 |
| 滑木高度（mm） | 默认 90 |
| 框架厚度（mm） | 0 表示无木框架；默认 0 |
| 钢带数量（道） | 2–6，默认 4 |
| 钢带宽度（mm） | 20–40，默认 30 |
| 钢带方向 | 横向 / 纵横，默认横向 |
| 进叉方向 | 四向 / 两向，默认四向 |

### 外尺寸与构件

- 外长 / 外宽 = 内尺寸 + 2 × 面板厚 +（框架厚度 > 0 时 2 × 框架厚度）。
- 外高 = 内高 + 底板厚 + 盖板厚 + 滑木高度。
- 派生构件：滑木 3、底板 1、侧板 2、端板 2、盖板 1、立柱（框架 > 0 时 4）、钢带（按数量与方向）。
- 钢带横向时按外宽包覆；纵横时增加沿长方向的钢带，数量按配置均分。

### 校验与页面

- 钢带数量 ≥ 2；框架厚度为 0 时钢带至少 2 道；其余按 R-013。
- 左栏参数分组：基本参数 / 箱体尺寸 / 钢带 / 载荷；外尺寸只读。
- 3D 与图纸显示钢带构件（横向 / 纵向分别按构件行派生）；钢带详图仍待确认（见 R-包装设计-008）。

### R-托盘设计-002：构件编辑与木材料单

| 字段 | 口径 |
| --- | --- |
| 层级 / 行序 | 构件从上层到下层的实际顺序；拖动调整后图纸与总高联动 |
| 构件类型 | 面板 / 端板 / 中间纵梁板 / 墩块 / 底板 / 纵梁 / 滑木 / 胶合板面板 / 垫块 / 自定义 |
| 名称 | 手填，默认取构件类型名；用于图纸标注与料单 |
| 材料 / 树种 | 从材料目录选择 |
| 方向 | 沿长度（x）/ 沿宽度（y） |
| 长度 / 宽度 / 厚度（mm） | 整数毫米，必填且 > 0 |
| 数量 | 正整数，必填且 ≥ 1 |
| 损耗（%） | 0~100，默认 8；采购体积 = 净体积 ×（1 + 损耗） |
| 加工费（元/件） | ≥ 0，默认 0；按件计 |
| 单价覆盖（元/m³） | 0 表示使用材料目录单价；> 0 只覆盖本行 |

计算口径：

- 净体积（m³）= 长 × 宽 × 厚 × 数量 ÷ 10⁹，保留 5 位小数。
- 采购体积（m³）= 净体积 ×（1 + 损耗），保留 5 位小数。
- 重量（kg）= 采购体积 × 密度，保留 1 位小数。
- 材料费（元）= 采购体积 × 单价（或单价覆盖），保留 2 位小数。
- 加工费（元）= 数量 × 加工费，保留 2 位小数。
- 合计 = 各行分别求和；服务端保存时重算，不信任前端合计。

基础校验：至少一个面板或胶合板面层；至少一个墩块、纵梁或滑木支承；九墩块模板至少 9 个墩块、3 块中间纵梁板且中间纵梁板长度等于托盘宽度；任一尺寸或数量 ≤ 0、总高 ≤ 0 时阻止保存。
