# 托盘设计领域实现设计（pallet）

> 定位：托盘设计领域的**实现设计**（How）。需求见 `product/托盘设计.md`（R-托盘设计-001~005）。
> 全局约定见技术方案 §4（模块边界）/ §5（数据模型）/ §6（API 契约）/ §7（前端规范），本文件只写本领域落点，不重述约定。

---

## 1. 模块结构与职责

`modules/pallet` 为业务模块，遵循技术方案 §4.1 四件套模板：

```
modules/pallet/
├── pallet.controller.ts        # 项目 CRUD、复制、材料目录
├── pallet.service.ts           # 编号、项目与构件读写、合计重算
├── dto/
│   └── pallet.dto.ts           # 项目 / 构件 / 材料契约
├── pallet.module.ts            # exports: PalletService
└── index.ts                    # 唯一公开出口
```

- `pallet_projects`、`pallet_components`、`pallet_materials` 归本模块。
- 几何、BOM 与基础校验纯函数放 `packages/shared`（`pallet.*.ts`），服务端与前端共用。
- 本模块**不导入** CustomerModule / OrderModule；客户名称只作文本快照，不建外键、不生成销售单。
- 材料目录 v1 只读；租户首次读取时按默认值落库，后续由平台运营统一维护（本轮不做页面）。

## 2. 数据模型概览

> 细节归 `packages/db/prisma/schema.prisma`（表结构唯一事实源，技术方案 §5），此处只列概览与约定。

| 表 | 字段要点 | 备注 |
| --- | --- | --- |
| `pallet_projects` | 编号 `PD-#####`、名称、客户名称快照、结构模板、使用范围、进叉方向、长 / 宽（整数 mm）、总高（整数 mm）、目标载荷、载荷形式、合计体积 `decimal(18,5)`、合计重量 `decimal(18,1)`、材料费 / 加工费 `decimal(18,2)`、备注、软删除 | 编号唯一按租户复合；索引 `(tenant_id, updated_at)`、`(tenant_id, template_type)`；合计值由服务端重算落库 |
| `pallet_components` | 所属项目、行序、构件类型、名称、材料 code、方向、长 / 宽 / 厚（整数 mm）、数量、损耗 `decimal(5,4)`、加工费 `decimal(12,2)`、单价覆盖 `decimal(12,2)`、软删除 | 唯一 `(project_id, seq)`；`project_id` 外键级联；行序不回改 |
| `pallet_materials` | 材料 code、名称、密度 `int`、采购单价 `decimal(12,2)`、出口熏蒸、图纸颜色、是否系统预置 | 唯一 `(tenant_id, code)`；v1 只读；默认 11 种由服务首次读取时落库 |

枚举：

- `PalletTemplateType`：`BLOCK` / `STRINGER` / `NOTCHED` / `SKID` / `PLYWOOD` / `CUSTOM`
- `PalletComponentRole`：`TOP_DECK` / `END_DECK` / `STRINGER_BOARD` / `BLOCK` / `BOTTOM_DECK` / `STRINGER` / `RUNNER` / `PLYWOOD` / `SPACER` / `CUSTOM`
- `PalletOrientation`：`X` / `Y`
- `PalletDestination`：`EXPORT` / `DOMESTIC`
- `PalletLoadType`：`UNIFORM` / `CONCENTRATED`

通用字段（主键、`tenant_id`、`created_at/updated_at`、`deleted_at`）按技术方案 §5.1；`tenant_id` 不建外键，与现有业务表一致。

**构件更新口径**：项目整单更新时，旧构件行物理删除后按新行序重建（构件是项目子行，不是独立业务单据，无历史引用）；项目删除时项目与构件均软删除，项目详情与图纸不再可见。

## 3. 几何、BOM 与校验规则（纯函数）

### 3.1 几何模型

`packages/shared/src/pallet.geometry.ts`：

```ts
interface PalletPiece {
  x: number; y: number; z: number;   // 左下后角，mm
  l: number; w: number; h: number;   // 长宽高，mm
  role: PalletComponentRole;
  componentIndex: number;             // 对应构件表行号
  label: string;                      // 图纸与 tooltip
}

buildPalletGeometry(project, components): {
  pieces: PalletPiece[];
  L: number; W: number; H: number;
}
```

排布规则：

- 层级：构件表从上到下即物理层级；某构件的 `z` = 其下方全部构件高度之和。
- 面板 / 底板（方向 X）：沿 Y 均分 `q` 块；方向 Y：沿 X 均分 `q` 块。
- 中间纵梁板：方向 Y，长度 = 托盘宽度，沿 X 均分 3 块。
- 纵梁 / 滑木：方向 X，长度 = 托盘长度，沿 Y 均分 `q` 根。
- 墩块：按 `cols = ceil(sqrt(q))`、`rows = ceil(q/cols)` 网格均分。
- 胶合板：整张面板，一层。
- 自定义构件：按方向 X / Y 与数量均分；不做避让与碰撞检测。
- 开槽纵梁：构件类型 `STRINGER` 且名称含「开槽」或模板 `NOTCHED`；图纸绘制槽口轮廓。

### 3.2 2D 投影

`packages/shared/src/pallet.geometry.ts` 同时导出视图映射（只返回矩形，不碰 DOM）：

| 视图 | x | y | 宽 | 高 | 排序 |
| --- | --- | --- | --- | --- | --- |
| top | `piece.x` | `piece.y` | `piece.l` | `piece.w` | z 升序；低层半透明 |
| front | `piece.x` | `H - z - h` | `piece.l` | `piece.h` | y 升序 |
| side | `piece.y` | `H - z - h` | `piece.w` | `piece.h` | y 升序 |

- 轴测：`u = (x - y) * 0.866`，`v = (x + y) * 0.5 - z`；按 `z`、`x + y` 升序绘制。
- 单视图统一 fit：`min((框宽 - 2×边距) / 投影宽, (框高 - 2×边距 - 标注区) / 投影高)`，居中。
- 三视图拼版：主视（左上）、侧视（右上）、俯视（左下）、轴测（右下）。
- 尺寸标注：单视图底部标长、右侧标高；拼版不标。
- 构件颜色按 `PalletComponentRole` 固定；选中描边 `#b83e38`，普通描边 `#694a2f`。

### 3.3 3D 场景

`packages/shared/src/pallet.scene.ts` 只产出 mesh 描述，不依赖 Three.js：

```ts
type PalletMesh =
  | { kind: 'box'; center: [number, number, number]; size: [number, number, number]; color: string; componentIndex: number }
  | { kind: 'notchedStringer'; profile: [number, number][]; depth: number; transform: {...}; color: string; componentIndex: number };
```

- 普通构件 = `BoxGeometry`；开槽纵梁 = 侧面 `Shape` + `ExtrudeGeometry`。
- 正交相机，Z 轴向上；默认轴测角；`OrbitControls` 旋转 / 缩放 / 平移。
- `Raycaster` 选中 mesh，`userData.componentIndex` 与构件表联动。
- WebGL 不可用回退 2D 轴测图。

### 3.4 BOM

`packages/shared/src/pallet.bom.ts`：

- 净体积 = `l × w × h × q / 1e9`，5 位小数。
- 采购体积 = 净体积 ×（1 + 损耗），5 位小数。
- 重量 = 采购体积 × 密度，1 位小数。
- 材料费 = 采购体积 ×（单价覆盖 > 0 ? 单价覆盖 : 材料单价），2 位小数。
- 加工费 = 数量 × 加工费，2 位小数。
- 合计逐项求和；服务端保存时重算，前端只预览。
- 计算用 number；落库前按上述位数四舍五入，避免浮点尾差。

### 3.5 基础校验

`packages/shared/src/pallet.validation.ts`：

- 至少一个 `TOP_DECK` / `PLYWOOD`；
- 至少一个 `BLOCK` / `STRINGER` / `RUNNER`；
- 九墩块模板：`BLOCK` 数量 ≥ 9、`STRINGER_BOARD` 数量 ≥ 3，且中间纵梁板长度 = 托盘宽度；
- 构件尺寸 / 数量 > 0；
- 总高 > 0；
- 层级顺序异常时返回确认级提示，不阻断保存。

## 4. 编号生成

- 项目 `PD-#####`：事务内取 `PD-` 前缀最大流水 +1，唯一约束兜底并发，P2002 重试 3 次。
- 前缀登记见 `1-产品文档.md`「五、全局编号规范」。
- 删除为软删除，编号不回收。

## 5. 接口清单

> 契约由 NestJS 装饰器代码生成 OpenAPI（技术方案 §6.1 / ADR-006），本文只列清单。

| 接口 | 路径 | 用途 |
| --- | --- | --- |
| project-list | `GET /api/v1/pallet/projects` | 列表：名称 / 编号模糊、模板筛选、分页、更新时间排序 |
| project-detail | `GET /api/v1/pallet/projects/:id` | 详情：项目 + 构件 + 材料 + 合计 |
| project-create | `POST /api/v1/pallet/projects` | 新建（`PD` 编号；Idempotency-Key） |
| project-update | `PUT /api/v1/pallet/projects/:id` | 整单更新项目与构件，服务端重算合计 |
| project-remove | `DELETE /api/v1/pallet/projects/:id` | 软删除 |
| project-duplicate | `POST /api/v1/pallet/projects/:id/duplicate` | 深拷贝项目与构件，生成新编号 |
| material-list | `GET /api/v1/pallet/materials` | 只读材料目录（首次读取落默认值） |

错误码：

- `PALLET_NOT_FOUND`：项目不存在或已删；
- `PALLET_TEMPLATE_INVALID`：模板值非法；
- `PALLET_COMPONENT_INVALID`：构件尺寸 / 数量 / 方向非法；
- `PALLET_HAS_NO_COMPONENTS`：没有构件；
- `PALLET_CODE_CONFLICT`：编号冲突重试仍失败。

权限：`pallet:view`（列表 / 详情 / 材料 / 报告）/ `pallet:manage`（新建 / 更新 / 删除 / 复制）；功能 `pallet_design`。

审计：新建、更新、删除、复制写 `event_logs`，`domain = pallet`。

## 6. 跨模块边界

- 本模块不导入 customer / order / production；只存客户名称快照。
- 图纸、BOM、报告全部由本域数据计算，不读其他领域表。
- 后续如需生成销售单，由 order 域提供公开接口，本域只调 `index.ts` 导出，不直连表。

## 7. 前端实现节（web）

### 7.1 页面

- `/admin/pallet-design`：列表页；筛选、表格、分页、新建 / 编辑 / 复制 / 删除。
- `/admin/pallet-design/new`：新建；选模板后进入编辑器。
- `/admin/pallet-design/[id]`：编辑器；项目参数 + 2D / 3D 图纸 + 构件表 + BOM。
- `/admin/pallet-design/[id]/report`：打印报告。

### 7.2 组件

```
components/pallet/
├── pallet-editor.tsx           # 编辑器容器与保存
├── pallet-component-table.tsx  # 构件表
├── pallet-drawing-2d.tsx       # SVG 2D 视图
├── pallet-viewer-3d.tsx        # Three.js 3D 视图（动态加载）
├── pallet-view-switch.tsx      # 视图切换
└── pallet-bom-summary.tsx      # BOM 汇总
```

- 2D 用 React 渲染 SVG，不操作 DOM；尺寸与选中态由 props 驱动。
- 3D 用 `next/dynamic` + `ssr: false`，切到 3D 才加载 `three`；卸载时 dispose。
- 编辑器保存整单：`PUT /pallet/projects/:id`；新建 `POST` 后跳转 `[id]`。
- 表单 / 详情页使用 `PageFrame`；列表页沿用现有表格与筛选规范。
- 报告页打印时隐藏导航与按钮，A4 纵向；`window.print()`。

### 7.3 菜单与权限

- `lib/nav.ts` 新增独立「设计」分组（位于销售之后、采购之前），组内为「托盘设计」；`scope = pallet:view`，`feature = pallet_design`。
- `featureForPath` 增加 `/admin/pallet-design` → `pallet_design`。
- `scopeForPath` 增加新建 / 编辑 → `pallet:manage`，其余 `pallet:view`。
- `packages/shared/src/auth.permissions.ts` 增加 scope 与角色授权。

## 8. 数据迁移

- 只新增三张表与枚举，无破坏性改动。
- 迁移内为默认租户写入 `tenant_features`（`pallet_design` = true），便于首个租户使用；其他租户由平台运营开通。
- 材料目录不在迁移内批量写；服务首次读取时按默认值落库。
- `PD` 前缀为新前缀，无历史编号重排。

## 9. 测试

- 纯函数单测（最高优先级）：
  - 5 种模板的构件数量、总高、包围盒；
  - 俯视 / 主视 / 侧视映射与尺寸；
  - 开槽纵梁槽口点数；
  - BOM 手算样例；
  - 空构件、0 / 负尺寸、非法方向。
- 服务端集成：CRUD、编号、租户隔离、`pallet:view|manage` 403、feature 关闭 `FEATURE_DISABLED`、软删除、复制。
- 前端：2D / 3D 切换、构件表联动、保存后重载、打印版式；表单 / 详情页通过 PageFrame 骨架 E2E。
- 3D：数据层测试进 CI；WebGL 截图作为本地 / 可选验证，不作 CI 硬依赖。
