# 落地页领域实现设计（landing）

> 定位：落地页领域的**实现设计**（How）。需求见 `product/落地页.md`（R-落地页-001 / 002 / 003 / 004）。
> 全局约定见技术方案 §4（模块边界）/ §7（前端规范）/ §9（部署），本文件只写本领域落点。
> 本领域为平台类非业务领域，design 只含前端实现节；无后端模块、无表、无接口。

---

## 1. 路由与模块

- `/`：`apps/web/app/page.tsx`，Server Component，导出 `metadata`；不再重定向 `/login`。
- `/login`：仍归账号与权限领域，视觉与演示舞台复用本领域组件（见 §8）。
- 公开页面，不套 `AdminShell`、`MobileShell`、`OpsShell`；页面内容在 `components/landing/`。
- `/register`、`/ops/login` 与登录后分流保持不变。
- 无 scope、无 feature、不进入租户菜单、不计入账号额度。

## 2. 组件结构

| 组件 | 职责 |
| --- | --- |
| `landing/landing-header.tsx` | 深色悬浮导航：品牌、锚点（能力 / 流程 / 在线体验）、登录 / 免费注册；滚动后加深背景 |
| `landing/hero.tsx` | 首屏：价值主张、双 CTA、可玩 3D 舞台、数据徽标 |
| `landing/public-stage.tsx` | 公共托盘舞台：模板胶囊、2D / 3D、尺寸标注、结果条、桌面自动旋转 / 手机点击加载、WebGL 回退 |
| `landing/stage-3d.tsx` | 3D 包装：复用 `Viewer3D`，只读、无选中、无导出 |
| `landing/scroll-story.tsx` | 滚动三步叙事：桌面 sticky 舞台随步骤切换「结构 / 三视图 / 料单」，手机逐条展开 |

## 3. 演示数据流

- 模板取 `PALLET_TEMPLATE_OPTIONS`（五种，`custom` 不进入演示）；
- 构件 = `palletTemplateComponents(template, lengthMm, widthMm)`；
- 几何 = `buildPalletGeometry({ lengthMm, widthMm, templateType }, components)`；
- BOM = `calcPalletBom(components, PALLET_DEFAULT_MATERIALS)`；
- `lib/landing/demo.ts` 的 `buildDemoPallet` 返回 `{ geometry, bom, components }`，构件清单直接取 `components`，不再从几何反推；
- 展示：`geometry.L/W/H`、`bom.netVolumeM3`、`bom.weightKg`、`geometry.pieces.length`；
- 不调用 API、不带 tenant 上下文、不写库、不生成 `PD` 编号；演示不产生审计。
- 2D 用 `DrawingView2D`（`view` 可为 `iso` / `three`、`mini`）；3D 用 `Viewer3D`。

## 4. 3D 加载、旋转与回退

- 桌面：`PublicStage` 通过 IntersectionObserver 在进入视口（`rootMargin: 200px`）后挂载 3D；首个舞台在首屏即触发；
- 手机：默认只渲染 2D 轴测 + 「看 3D」；点击后才挂载；不自动起 3D；
- `next/dynamic` + `ssr: false` 懒加载 `stage-3d`；three.js 仍由 `Viewer3D` 内部动态 import；
- **自动旋转只在舞台处于视口内时开启**：`Viewer3D` 暴露 `setAutoRotate(enabled)`，仅切换 `OrbitControls.autoRotate` 与渲染循环，不重建场景；`useEffect` 不再依赖 `autoRotate`，几何变化才重建；
- 同页最多两个 3D 舞台（首屏、工作台）；滚动叙事与模板画廊只用 SVG，不新增 WebGL 上下文；
- 3D 只支持旋转 / 缩放 / 复位，不提供构件选中、导出；`hint` 传「拖动旋转 · 滚轮缩放」；
- WebGL 不可用：`PublicStage` 显示「当前浏览器不支持 3D，已切换为轴测图」，保留 2D；
- 卸载时释放 renderer / mesh / texture；DPR 上限沿用现有实现；无阴影、无地面、无外部贴图；
- `prefers-reduced-motion: reduce`：不自动旋转；用户仍可手动拖动。

## 5. 视觉系统与动效

- 全浅色，遵循 `product/平台布局.md` 的「纯白 + 强结构」基线：纯白画布、浅灰分区、边框与留白表达层级；品牌绿只用于主按钮、链接、眉标与选中态，**不做大面积铺底**。
- 颜色一律引用 `packages/tokens` 映射出的工具类（`bg-background` / `bg-muted` / `bg-card` / `border-border` / `text-foreground` / `text-muted-foreground` / `bg-primary` / `text-primary-foreground`）；不再定义 `[data-landing]` 私有色板，也不在组件里写十六进制或 `rgba()`。
- **唯一深色是 3D 画布**：`PublicStage` 在 3D 视图下使用 `bg-foreground` + `text-background`，2D 海报与工作台其余区域保持浅色；画布包在白卡内，不形成整屏深色。3D 木纹属于内容材质（技术方案 §7.2 例外），不随 UI 主题变化。
- 工具类只保留与颜色无关的部分：`.landing-stage-grid`（画布网格，颜色由 `var(--background)` 混合）、`.landing-reveal` / `.is-visible`（滚动揭示）、`.landing-float`（轻浮动）、`.landing-swap`（步骤切换入场）。
- 静态卡片用 `rounded-lg` + 边框，不使用装饰性阴影；按钮 / 输入框用 `rounded-md`；数字统一 `tabular-nums`。
- 动效只用 CSS 过渡 / 关键帧 + IntersectionObserver；不引入动画库。
- `prefers-reduced-motion: reduce` 时：关闭自动旋转、位移动画与揭示初始位移，直接显示最终态。

## 6. 首屏与滚动叙事

- 首屏桌面两栏：浅色白底，左文案（标签、主标题、说明、CTA、数据徽标），右白卡内 `PublicStage`（模板胶囊 + 深色 3D 画布 + 尺寸标注 + 结果条）；手机单列，舞台压缩到 4:3，先出浅色 2D 海报。
- 滚动叙事桌面：两栏，左侧 `position: sticky; top: 96px` 舞台（白卡 + 2D 图纸），右侧三个 `min-h-[58vh]` 步骤块；IntersectionObserver（`rootMargin: -42% 0px -42% 0px`）切换激活步骤，舞台用 `key={step}` 重放入场动画。
- 舞台内容按步骤：结构 → 轴测图 + 结构说明；三视图 → `view="three"`；料单 → 构件清单（取前 5 行 + 合计）。
- 手机：三个步骤各自内嵌对应小图 / 清单，不做 sticky，避免滚动抢占。
- 该区不加载 three.js，也不使用深色背景。

## 7. 在线工作台与全屏

- `demo-section` 持有 `template`、`lengthMm`、`widthMm`，`buildDemoPallet` 一次计算后传给画廊、迷你工作台与全屏，保证三处同源。
- 画廊卡片：默认尺寸轴测缩略图 + 名称 + 默认长宽；点击设置模板（同时恢复该模板默认长宽），并 `scrollIntoView({ behavior: 'smooth', block: 'start' })` 到 `#workbench` 工作台。
- 迷你工作台桌面四区：`220px | minmax(0,1fr) | 260px` 上三栏 + 下方 BOM 表；手机顺序堆叠为「参数 → 舞台 → 模板 → 清单」。
- 参数：长 / 宽滑杆（`range` 数据仍取 `DEMO_LENGTH_RANGE` / `DEMO_WIDTH_RANGE`），展示 `mm`；模板通过左侧列表切换。
- 全屏：共享 `Dialog`，`DialogContent` 覆盖整个视口（`h-[100dvh] w-full max-w-none rounded-none`），内含同一 `PublicStage`、参数与 BOM；`showCloseButton={false}`，自定义中文关闭按钮；ESC 由 Dialog 处理；关闭后组件状态自然保留。
- 全屏内滑杆 id 用 `useId` 前缀，避免与工作台实例重复。

## 8. 登录 / 注册共用（账号与权限领域调用）

- 新增共享外壳 `components/auth/auth-shell.tsx`，登录页与注册页都以它包裹表单；根节点加 `data-landing`。
- 桌面 `lg` 以上左右分栏：左表单（品牌、标题、说明、表单、底部链接、能力说明），右浅灰面板（`bg-muted/30`）内放 `PublicStage`（`block` 模板、1200×800、自动旋转、模板可切换、深色 3D 画布）。
- 小于 `lg`：表单优先；顶部只保留压缩品牌条 + 静态轴测海报（`DrawingView2D`），**不挂载 3D**。
- 登录字段、`loginSchema` 校验、记住登录、错误提示、`authSession` 与成功后分流均不变；注册字段、`registerSchema` 校验、两次密码一致校验与成功后分流均不变，仅补密码显示 / 隐藏切换。
- 认证页不新增接口、不写库；舞台数据来自 `buildDemoPallet` 纯函数。
- 两个页面的表单、文案与提交逻辑仍各自持有，外壳只负责布局、品牌、舞台与手机海报，避免把鉴权逻辑抽进通用组件。

## 9. 移动端与性能

- 断点 767px（Tailwind `md`）；认证页分栏在 `lg`；
- 底部固定「免费注册」条（安全区内边距），页尾 CTA 进入视口时隐藏；
- 触控目标 ≥44px；页面无横向滚动；预览区固定宽高比，避免 CLS；
- 首屏不加载 three.js 组件本体；`PublicStage` 进入视口后再挂载；离开视口停止旋转；
- 深色只出现在 3D 画布，LCP 区域（首屏文案与 2D 海报）保持浅色；
- SVG / 系统字体；不引入外部大图、视频或动画库。

## 10. SEO 与品牌文案清单

- `metadata`：标题、描述、OG（`app/page.tsx`）；与页头品牌一致。
- 品牌出现位置（换名时逐项替换，不抽品牌常量）：`app/layout.tsx` 的 metadata、`app/page.tsx` 的 metadata、落地页页头与页脚、首屏与登录页舞台说明、登录页副标题、注册页说明、README、`product/账号与权限.md`、本领域文档。

## 11. 测试

- E2E 桌面：`/` 不被重定向；首屏标题与舞台可见；模板胶囊切换后尺寸变化；滚动画廊选中结构后工作台同步；滑杆调宽后尺寸 / 清单更新；全屏打开、调参、ESC 关闭；3D canvas 或回退文案；CTA → `/register`；登录 → `/login`。
- E2E 手机（390×844、360×800）：底部 CTA、首屏压缩、工作台堆叠、点击「看 3D」、无横向滚动。
- E2E 减弱动效：`emulateMedia({ reducedMotion: 'reduce' })` 后舞台 `data-auto-rotate="false"`，内容可见。
- 登录 / 注册 E2E：桌面右侧舞台可见（`login-stage` / `register-stage`）；手机舞台隐藏、表单可见；原有登录、注册流程回归。
- 现有后台 E2E 回归；`pnpm docs:check` 通过。
- 人工：Lighthouse 移动端、微信内置浏览器真机检查。

## 12. 边界

- 不嵌入上传的原型 HTML；不复制包装工作台；不做多品类；不做多页官网。
- 演示不产生数据、不调用接口、不写审计；全屏不写 URL 状态。
- 不引入动画库、外部图片 / 视频；不做主题切换。
