## 一、业务现状分析

### 业务特征

| 特征 | 现状 |
| --- | --- |
| 生产模式 | 以销定产，有订单才生产 |
| 库存管理 | 无库存概念，无批次概念 |
| 加工方式 | 根据订单要求，随机选择原木加工 |

### 收入结构

| 类型 | 说明 | 管理现状 |
| --- | --- | --- |
| 主要收入 | 板材销售 | 有单据记录，有客户欠款追踪 |
| 次要收入 | 加工废料出售 | 待确认 |

### 支出结构

| 类型 | 说明 | 管理现状 |
| --- | --- | --- |
| 主要支出 | 采购原木 | 无采购单、无采购账本 |
| 日常开支 | 待梳理 | 无记账 |
| 工人工资 | 按方数计算，每人单价不同 | 有每日加工记录作为依据 |

### 客户情况

- 当前5-6家活跃客户（以前30-40家，流失严重）
- 客户持续流失（外地木材更便宜）
- 收款以账期形式
- 对账习惯：客户付款时对账，无定期对账

### 当前已有记录

1. **每日加工记录**：加工完成数量及方数（用于计算员工工资）
2. **销售订单记录**：每位客户的出货单据、金额、欠款总额（回款即减）

### 核心痛点

1. **采购完全无序**：无采购单、无采购账本，成本失控
2. **客户持续流失**：外地竞争+账期收款，现金流压力大
3. **财务黑洞**：支出无记账，收入支出无法对账
4. **无库存管理**：原木和板材均无库存概念，无法核算成本

## 二、需求调研

### 生产与工资模块（2026-05-09）

| # | 主题 | 核心问题 | 调研结论 |
| - | ---- | ---------------------------------------------------- | ------------------------------------------ |
| 1 | 工资计算 | 工资按成品单方数算还是另有独立记录？多人协作怎么分方数？不同工种单价是否不同？有无底薪？ | 总方数 × 165元/方 = 生产总工资，所有规格统一价，领班线下按上工天数分给工人 |
| 2 | 次品处理 | 切坏原木/次品时工资怎么算？有无惩罚扣款？成品单谁填写？争议以谁为准？不同规格/厚度/树种是否影响单价？ | 发货后客户不满意才叫次品，扣减总方数 |
| 3 | 员工情况 | 固定几人？忙时是否加临时工？离职工资怎么结？有无包工头？是否有日结工？ | 5个工人固定，1个修锯师傅（3100/月），无临时工 |
| 4 | 工资发放 | 月结/半月结/完工结？跨月方数算哪月？ | 一季度一发（收麦、收秋、过年），月度核算按月计提 |
| 5 | 借支 | 是否有预支工资的情况？频次高吗？工资结算周期和销售/采购的月度周期是否对齐？ | 偶尔有，频次低 |
| 6 | 排产逻辑 | 订单谁接？包含哪些信息？多订单如何排序？做不完怎么处理？客户改单怎么办？ | 按经验，客户优先级，无固定规则 |
| 7 | 原木拣选 | 工人挑原木的规则？切完订单后余料怎么处理？ | 按产品规格选，无批次概念；余料待确认 |
| 8 | 成品单 | 成品单记录什么？和销售单的关系？ | 只记加工量（日期+客户+方数），销售单另有单据 |

### 采购模块（2026-05-17）

**一、采购基础**

| # | 核心问题 | 调研结论 |
| - | ---------------------- | ------------------- |
| 1 | 原木从哪买？固定几个供应商还是随机找？ | 大部分固定，也有随机 |
| 2 | 谁去买？爸妈去选货还是供应商送上门？ | 送货上门为主，偶尔自提（付运费） |
| 3 | 多久采买一次？有规律还是看感觉？ | 看感觉，无固定规律 |
| 4 | 一次买多少？按车？按方？按需？ | 按吨计价 |
| 5 | 怎么定价？按方议价？按车估堆？统价？ | 按吨计价 |
| 6 | 付款方式？现结？有账期？ | 对公/微信/现金，大部分现金，偶有欠款 |
| 7 | 采购时有没有书面单据？还是口头谈完直接卸货？ | 有书面单据 |

**二、质检**

| # | 核心问题 | 调研结论 |
| -- | -------------------------------- | ------------------------ |
| 8 | 收到原木时有没有检查？看什么？树种？直径？长度？弯曲度？ | 爸妈检查，看虫眼等 |
| 9 | 质量不好的原木怎么处理？拒收？折价收？照收？ | 折价收（如1.5吨按1吨计），加工后发现问题自认 |
| 10 | 质检谁来做？爸妈？工人？供应商说了算？ | 爸妈做 |
| 11 | 有没有出现过后才发现质量问题的？比如加工时才发现木头里面是坏的？ | 有，自认 |

**三、卸货入库**

| # | 核心问题 | 调研结论 |
| -- | --------------------------- | ---------------- |
| 12 | 原木卸在哪里？院子里？有没有分区堆放？ | 无固定分区，按规格简单堆垛 |
| 13 | 卸货谁干？自己的工人还是供应商管卸？ | 父亲为主，工人偶尔帮忙，无卸货费 |
| 14 | 卸货费算在采购价里还是单独算？ | 包含在采购价内 |
| 15 | 院子里堆的原木有没有分类？按树种？按大小？还是随便堆？ | 无固定分区，无批次概念 |
| 16 | 不同批次的木头混在一起能分辨吗？ | 不能，不具备批次管理基础 |

**四、库存货值确认**

| # | 核心问题 | 调研结论 |
| -- | ----------------------------- | ----------------------------- |
| 17 | 目前对院子里还剩多少原木有概念吗？ | 原木大概知道，每季度盘点（吨×单价）；未出货板材看大概方数 |
| 18 | 加工到一半的（已切但还没出货的板材）怎么算？ | 有存货，算库存 |
| 19 | 月底如果看院子里原木+未出货板材值多少钱，现在能算出来吗？ | 季度盘点可估算 |
| 20 | 原木的价格波动大吗？ | 不大 |
| 21 | 有没有做过实物盘点？ | 每季度盘点 |

> **关键发现**：月度毛利公式需考虑库存变动——采购量和消耗量不等时，用采购总额替代消耗成本会导致毛利失真，季度盘点时手动调整即可。

### 销售模块（2026-05-11）

| # | 主题 | 核心问题 | 调研结论 |
| - | ----- | -------------------------------- | ------------------------------- |
