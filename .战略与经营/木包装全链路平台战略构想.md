## 一、为什么转型：背景与定位转变

### 1.1 现状

MCC 系统当前定位为家庭式木包装箱厂的经营管理平台（以销定产、手工记账、账期收款），已完成阶段一（线上化）：账号权限、订单、财务基础模块上线并通过 E2E 回归。

### 1.2 转型决策

将愿景从「单一工厂经营管理平台」升级为：

**木包装行业的全链路产业平台**——一端接需求端（买家询价、自助出方案、下单购买），一端接供给端（工厂报价、生产、发货、收款），底层接原料端（原木/板材供应商行情信息），平台居中以交易担保与增值服务变现。

### 1.3 转型的本质与三大挑战

转型的本质：客户从「自家工厂」变为「平台双边用户」，产品从**工具**升级为**市场**。三大挑战决定一切打法：

| 挑战 | 说明 | 应对（详见后文） |
| --- | --- | --- |
| 双边冷启动 | 买家因卖家而来，卖家因买家而来，先有鸡先有蛋 | 自家厂先当供给侧（样板供给），买家端工具免费开放抓需求 |
| 公信力悖论 | 自家厂既是平台运营方又是卖家，加盟厂凭什么信你 | 「区域保护 + 让单」规则白纸黑字公示，让单先于自营 |
| 资金合规 | 平台代收货款形成资金停留，触碰支付监管红线 | 走持牌支付分账通道，平台不建资金池 |

## 二、战略收敛结论（决策总表）

| # | 主题 | 结论 | 决策理由 |
| --- | --- | --- | --- |
| 1 | 平台定位 | 全链路一体化，分三步落地 | 愿景铺满全链路，落地按阶段收敛 |
| 2 | 切入品类 | 托盘 + 木箱并行；原料端第一功能为集采拼单（行情信息展示后置） | 托盘标准化高、木箱是自家厂基本盘；拼单集采是工厂获客钩子，行情信息仅是展示 |
| 3 | 自家厂角色 | 样板 + 深度运营；区域保护 + 让单 | 自家厂是唯一真实供给与产品实验室；让单换加盟信任 |
| 4 | 变现模式 | 交易佣金 + 增值服务分成；无订阅费 | 工具免费获客；收入押在交易与服务，与担保闭环咬合 |
| 5 | 现金流过渡 | P1 自营单利润造血 | 佣金需交易量支撑，前期收入等于自营利润 |
| 6 | 买家端形态 | 询价工单 + AI 描述（自助出方案） | 门槛最低的获客入口；quote 领域讨论稿已深度设计 |
| 7 | 工厂端形态 | MCC 多租户工作台（一租户一工厂） | 复用现有系统，平台化是文档与租户改造而非重写 |
| 8 | AI 发力点 | 先买家询价助手 | AI 管「理解与解释」，规则引擎管「算价」，获客价值最大 |
| 9 | 核心机制 | 平台担保交易：担保结算 + 平台组织验收 | 咬住资金流防飞单，验收沉淀信用数据 |
| 10 | 合规底线 | 持牌分账，不建资金池 | 规避二清风险，为供应链金融铺路 |
| 11 | 报价权 | 自营期平台规则引擎直出价；加盟期「平台代报 + 供方确认订价」（集采拼单机制） | quote 稿与拼单原型先后推进，两阶段报价权均已定（详见 5.1、八） |
| 12 | 工厂获客钩子 | 集采拼单（材运运原型）：先拼板材省钱，再开放接单 | 工厂端的「买家端工具」；与买家端 quote 同构的获客逻辑 |

## 三、三步走落地节奏

### 样板供给期（P1）——跑通自营闭环

- **目标**：把「自助出方案 → 下单 → 生产 → 发货 → 验收 → 收款」整条链在自家厂跑通，形成真实可交易的供给。
- **关键动作**：上线买家端自助出方案（[quote.md](..\AAAdocs\product\quote.md) 的 P0/P0.5/P1）；平台担保结算上线；自家厂 MCC 工作台承接订单；集采拼单假门验证（微信群人工撮合，不建设功能，见第八节）。
- **出期信号**：外部客户不再经过微信人工咨询，直接网页自助出方案并完成首笔担保交易。

### 双边闭环期（P2）——引入加盟工厂

- **目标**：引入区域互补的加盟工厂，平台从「自营」走向「双边」，抽佣收入启动。
- **关键动作**：分单规则引擎（区域保护 + 让单）上线；平台规则公示；履约信用沉淀；集采拼单上线（工厂获客钩子 + 原料端第一功能）；原料端行情信息展示上线。
- **出期信号**：加盟工厂通过平台成交的订单占比持续爬升、拼单批次按时成团，且无飞单投诉。

### 服务变现期（P3）——增值服务分成

- **目标**：交易量支撑下接入检测认证、熏蒸/IPPC、物流、供应链金融，赚服务分成。
- **关键动作**：接入第三方服务机构；基于 P2 信用数据设计金融服务。
- **出期信号**：增值服务成单率与客单价达到商业计划书设定的门槛。

### 三个决策点的结论

- **① 报价权（已闭环）**：quote 领域讨论稿给出了比「平台代报 + 工厂确认」更坚决的答案——**自营样板期内，报价由规则引擎直出，大模型绝不碰价格**。理由：自营期平台自己就是工厂，不存在「让谁确认」的问题；买家要的是确定、可复现、可解释的分钟级报价。**加盟期流程同步闭环**：采用集采拼单原型的「平台代报 + 供方确认订价」机制（板材价随行情波动，订价必须供方确认），详见第八节。
- **② 结算节点（已定）**：平台担保结算——买家款先进平台（持牌分账通道），验收通过后放款给工厂并抽佣。咬住资金流防飞单，顺带解决行业账期欠款痛点。
- **③ 验收责任（已定）**：平台组织验收——发货/到货拍照留存 + AI 辅助验收，作为放款依据；同时沉淀履约信用数据，是未来金融分成的本钱。

## 八、集采拼单领域（工厂获客钩子）

### 8.1 定位与原型

一句话：**集采拼单是工厂端的「买家端工具」**——不直接从工厂赚钱，先用「一起拼板材采购省钱」把小厂拉上平台，成为 P2 加盟工厂获取的武器。

原型：高保真交互原型「材运运 · 木业板材拼单集采」（单文件 HTML、移动端优先）已验证核心交互形态：发起拼单 → 加入集采批次 → 供方确认订单 → 付款 → 装车干线 → 城市分拨 → 送达企业。

### 8.2 痛点与机制

**痛点**：小木包装厂单采量小，拿不到整车价；干线运费摊薄差；板材厂对小单爱答不理、议价无力。

**机制**（与 quote 的嘉立创逻辑同构）：

| | quote（买家端） | 集采拼单（工厂端） |
| --- | --- | --- |
| 聚合什么 | 「说不清的需求」→ 标准参数 | 「散碎小单」→ 整车集采批次 |
| 平台价值 | 傻瓜自助 + 分钟报价 | 集采议价 + 平摊干线运费 + 城市分拨 |
| 目标用户 | 设备厂/外贸采购 | 上海周边小木包装厂 |

核心动作链：**成团门槛 + 截止时间**（「再加 240 张成团，18:30 截止」）→ **供方确认数量/价格/交期** → 装车（17.5 米整车）→ 干线运输 → 城市分拨配送。

### 8.3 机制决策（本次拍板）

| 决策点 | 结论 |
| --- | --- |
| 报价与订价 | 平台代报 + 供方确认订价（板材价随行情波动，订价必须供方确认）——此即 P2 加盟期报价确认流程的落地机制，战略待定项「加盟期报价确认流程」由此闭环 |
| 成团冷启动 | 自家厂常驻参团兜底成团；种子批次用微信群人工撮合 |
| 资金流 | P2 前期不过平台资金（现金/对公直付），订单与付款状态留痕照做；交易量起来后接入持牌分账 |
| 变现方式 | 集采协议价差为主，干线/分拨服务费为辅；财务模型进商业计划书 |
| 验证节奏 | P1 期假门/微信群人工撮合先行验证「小厂愿不愿意拼」；与 quote 验证「买家愿不愿意自助」是两个独立假设，不混在同一个 MVP 里测，均用同一套五步验证法 |

### 8.4 与三步走的位置

- P1：仅做假门验证（不建设功能）；
- P2：正式上线，作为原料端第一功能与加盟工厂获取武器；
- 参与拼单的小厂在此过程中自然完成入驻、认证、信用种子数据积累，P2 开放接单时已在池内。

## 十二、风险备忘与待定项

### 风险备忘

1. **现金流空窗**：无订阅费，佣金与分成需交易量支撑，P1 完全依赖自营单利润过渡——自营利润模型需在商业计划书中量化。
2. **防飞单**：担保结算 + 服务捆绑是主防线，必须保持结算、履约环节的平台唯一性；任何放开「直付」的口子都要单独评估。
3. **公信力**：自家厂既是裁判又是运动员，「区域保护 + 让单」规则必须透明公示；让单执行情况纳入平台经营报表。
4. **合规红线**：二清风险一次违规即致命，支付通道选型前置到 P1 启动前完成。
5. **需求证伪**：quote.md 已写明证伪条件（自助入口提交率低、客户还是要找人聊、引擎报价成交率倒挂）——出现任一即承认假设不成立，止损条款提前生效。
6. **成团兜底成本**：自家厂常驻参团意味着垫资与库存风险，需设定单批兜底上限与止损规则（连续成团失败即暂停该区域批次）。
