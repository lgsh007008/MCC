# 股权分配与季度分红机制

> 定位：第一阶段家族工厂的股权与分红执行草案。
> 适用前提：四位股东（大姐 40%、父母 30%、二姐 20%、你 10%）；**不设股东工资、不设父母养老津贴**；只有“分红、再投入、旧应收”三块钱。
> 状态：草案 v0.4（2026-11-10）。v0.4 按当前讨论简化分红公式，直接用当季利润；待四位股东确认后执行；不构成法律或税务意见。

---

## 一、前提与假设

1. 未来经营主体为**干净的新公司**（或已完成风险隔离的经营主体）；旧公司/旧应收单独建账管理。
2. 股权结构：大姐 40%、父母 30%、二姐 20%、你 10%。
3. 大姐全权负责日常经营；**40% 分红包含经营责任，不另发工资**。
4. 父母退休，不参与经营；**30% 分红是父母的主要回报，不另发养老津贴**。
5. 二姐不参与经营，只按 20% 分红；你只按 10% 分红，但前期系统改造由你主导。
6. 系统改造的软件、硬件、外包等费用由公司承担；你个人垫付的，记股东借款或出资，不计入分红。
7. 父母此前的对外应收账款（下称“旧应收”）不进入新公司可分配利润；客户回款进新公司账户，按“一个账户、两本账”拆分，旧账部分记“其他应付款—旧侧”，按期转交，不参与分红。
8. 本方案只解决“钱怎么分”，不解决股权登记、婚姻/继承、旧公司注销等法律事项；这些另行处理。

> 说明：工人工资属于经营成本，不是股东工资；本方案“不设工资”仅指四位股东。

---

## 二、股权结构

| 股东 | 比例 | 角色 | 分红依据 |
| --- | --- | --- | --- |
| 大姐 | 40% | 经营负责人，全权负责日常经营 | 40% 分红（含经营责任，不另发工资） |
| 父母 | 30% | 退休，不参与经营 | 30% 分红；旧账回款按两本账结算，可补充现金流 |
| 二姐 | 20% | 不参与经营，家庭成员 | 20% 分红 |
| 你 | 10% | 主导系统改造与前期改革 | 10% 分红；系统费用由公司承担 |

> 父母 30% 内部如何登记（父亲/母亲各自比例），在办理工商登记时另行确定；本方案按一个 30% 股东池计算。

---

## 三、三块钱：分红、再投入、旧应收

### 3.1 分红

- 来源：公司税后利润，扣除再投入预留后的可分配部分。
- 频率：按季度预分红，年度结算多退少补。
- 分配：按 40/30/20/10。
- 税务：个人股东分红按 20% 缴纳个人所得税，由公司代扣代缴。

### 3.2 再投入

- 来源：公司留存利润，不改变股权比例。
- 用途：设备、维修、环保/安全、系统、搬迁、流动资金、风险储备。
- 规则：年度列预算，季度先留后用；再投入不足时，分红减少或暂停。
- 增资：如股东会决定增资，另签增资协议，不默认按分红比例自动增资。

### 3.3 旧应收

- 归属：旧公司/父母，不属于新公司收入。
- 收款：客户只向新公司账户付款，不要求客户分两个账户。
- 分账：每笔回款按约定比例拆成“旧账部分”和“新单部分”，默认 50% / 50%；旧账清完后 100% 归新单。
- 记账：旧账部分记“其他应付款—旧侧”，不是收入，不进利润、不进分红；按月/季度转交旧侧。
- 调整：新公司现金紧张时，可临时提高新公司留存比例（如 30% 旧 / 70% 新）；旧侧急用钱时反向调整；比例写入季度规则。
- 用途：旧账部分先付旧公司税款、债务、清算费用；剩余归父母（或旧公司股东）。
- 坏账：由旧侧承担，不拖累新公司。

## 四、季度分红的计算规则

### 4.1 三个核心数字

**P：当季管理净利润**

```
P = 销售收入（仅新单，不含旧账部分）
    - 销售成本（期初库存 + 本期采购 - 期末库存）
    - 经营费用（工人工资、运费、水电、房租、维修、保险、合规）
    - 折旧
    - 税费（增值税及附加、预计企业所得税）
```

> 如果暂时做不到严格权责发生制，至少用季度盘点调整库存，避免“采购额当成本”导致利润失真。

**F：季末可分配现金**

```
F = 季末银行余额 + 现金
    - 最低现金储备
    - 未付供应商/工资/社保/税费
    - 下季度已确定的大额支出（设备、维修、环保、安全、搬迁、系统）
    - 待转旧账（其他应付款—旧侧）
```

**E：累计未分配利润**

```
E = 期初留存收益 + 本季净利润 - 已分红
```

### 4.2 分红公式

```
可分配利润 = P
本次分红 D = min(可分配利润 × 分红比例, F × 分红比例, E)
```

- 如存在以前年度亏损，先弥补亏损，再分红。
- 任一结果为负：本次不分红，累计到下一季度。
- 分红比例：第一年建议 50%；储备充足后提高到 70%；有大额再投入时降到 30%–40% 或暂停。
- 分红后必须保留至少 3 个月固定开支 + 下季度税费 + 已定大额支出。

### 4.3 最低现金储备

建议按以下三项之和：

1. 3 个月固定经营开支（工人工资、房租、水电、运费、日常费用）；
2. 下季度预计税费（增值税、附加、企业所得税、社保）；
3. 已确定的大额支出（设备、维修、环保、安全、搬迁、系统）。

采购旺季或客户账期拉长时，最低储备提高到 6 个月。

### 4.4 计算示例

> 示例按 70% 分红比例演示；第一年建议按 50% 执行。

| 项目 | 金额（万元） | 说明 |
| --- | --- | --- |
| 当季管理净利润 P | 20 | 已扣成本、费用、税费、折旧 |
| 可分配利润 | 20 | 等于 P（本版不设前置扣减） |
| 季末银行余额 | 35 | 含客户回款；其中待转旧账已列为负债 |
| 减：最低现金储备 | 20 | 3 个月固定开支 + 下季度税费 |
| 减：未付供应商/工资/税费 | 8 | 已发生未支付 |
| 减：已定大额支出 | 0 | 本季度无 |
| 减：待转旧账（其他应付款—旧侧） | 5 | 不属于新公司收入 |
| 可分配现金 F | 2 | 35 - 20 - 8 - 0 - 5 |
| 本次分红 D | 1.4 | min(20×70%=14, 2×70%=1.4, E) |
| 大姐 40% | 0.56 | |
| 父母 30% | 0.42 | |
| 二姐 20% | 0.28 | |
| 你 10% | 0.14 | |
| 代扣个税 20% | 0.28 | 按分红总额 1.4 计算 |
| 实付合计 | 1.12 | 1.4 - 0.28 |

> 示例说明：账面利润 20 万，但现金只够分 1.4 万；这是现金约束，不是利润造假。若季末现金为 50 万，F=17 万，分红为 min(14, 11.9)=11.9 万。

## 五、季度操作流程

| 时间 | 动作 | 产出 |
| --- | --- | --- |
| 季末后 10 日内 | 结账：银行、现金、应收应付、库存、税费、旧账拆分 | 季度财务报表 |
| 第 15 日前 | 计算 P、F、E、D | 分红计算表 |
| 第 20 日前 | 股东会决议（四位股东签字） | 分红决议 |
| 第 25 日前 | 支付分红，代扣 20% 个税 | 银行回单、个税申报 |
| 年度终了后 | 审计/结账，多退少补 | 年度分红结算表 |

> 季度分红属于“预分红”，年度按最终利润结算；多分部分从下季度/下年度分红中扣回，或由股东退回。

---

## 六、年度结算与多退少补

1. 年度终了后，完成年度账务结账/审计，确认全年净利润、可分配利润。
2. 汇总全年已预分红金额。
3. 计算全年应分红金额：

```
全年应分红 = min(全年可分配利润 × 年度分红比例,
                 全年可分配现金 × 年度分红比例,
                 累计未分配利润)
```

4. 多退少补：
   - 已分 > 应分：超出部分作为预分红，从下一年度分红中扣回，或由股东按比例退回。
   - 已分 < 应分：差额在年度结算后补发。
5. 年度结算需股东会决议，并留存报表、分红表、银行回单、个税申报记录。

## 七、旧应收账款的处理

### 7.1 单独建账

| 字段 | 说明 |
| --- | --- |
| 客户 | 旧客户名称 |
| 金额 | 原始应收金额 |
| 账龄 | 发生日期、逾期天数 |
| 证据 | 送货单、对账单、合同、微信记录 |
| 已回款 | 累计回款 |
| 未回款 | 余额 |
| 坏账判断 | 可收回/有争议/疑似坏账 |
| 处理人 | 谁负责催收 |

### 7.2 一个账户、两本账

- 客户只向新公司账户付款，不要求客户分两个账户。
- 每笔回款按约定比例拆成两本账：旧账部分、新单部分。默认 50% / 50%；旧账清完后 100% 归新单。
- 旧账部分记“其他应付款—旧侧”，不是收入，不进利润、不进分红；按月/季度转交旧侧。
- 新公司现金紧张时，可临时提高新公司留存比例（如 30% 旧 / 70% 新）；旧侧急用钱时反向调整；比例写入季度规则。
- 待转旧账余额不计入新公司可分配现金 F。

### 7.3 旧账部分的转交顺序

1. 旧公司欠税、滞纳金、罚款；
2. 旧公司供应商欠款、工人工资/社保；
3. 旧公司清算费用；
4. 剩余部分归父母（或旧公司股东），可按季度结算。

### 7.4 转让给新公司（如发生）

- 默认不转让；采用“一个账户、两本账”的委托收款模式，旧应收仍归旧侧。
- 如确需转让，必须按公允价值（考虑坏账风险）购买，不能免费或低价；
- 通知债务人，签债权转让协议；
- 依法申报纳税；
- 转让后的回款才进入新公司收入，并相应纳入新公司可分配利润。

## 八、特殊情形

| 情形 | 处理 |
| --- | --- |
| 当季亏损 | 不分红；累计亏损弥补后再分 |
| 账面有利润但现金不足 | 不分或少分，累计到下一季度 |
| 当季有大额再投入 | 先留再投，分红减少或暂停 |
| 客户账期拉长/库存积压 | 提高最低现金储备，降低分红比例 |
| 年底利润低于已预分 | 多分部分从下期分红扣回，或股东退回 |
| 旧账回款 | 按两本账拆分，旧账部分记其他应付款，不进入新公司分红 |
| 股东临时用钱 | 走股东借款协议，不叫分红；约定利息/还款 |
| 公司需要增资 | 另签增资协议，不默认按分红比例自动增资 |
| 大姐完全靠分红生活 | 可设“最低季度预分红”，但须满足累计利润和现金储备条件；否则视为借支 |

## 九、税务与合规要点

1. **先税后分**：增值税、附加、企业所得税、社保、工资先结清，再分红。
2. **分红个税**：个人股东分红按 20% 缴纳个人所得税，公司代扣代缴。
3. **亏损弥补**：以前年度亏损未弥补完，不得分红。
4. **不得违法分配**：不得分配公司资本，不得在资不抵债时分红；违法分配可能被要求退回，相关责任人可能承担责任。
5. **记录完整**：股东会决议、财务报表、分红表、银行回单、个税申报记录齐全。
6. **旧账不混同**：旧账部分记“其他应付款—旧侧”，不得进入新公司收入或分红计算；委托收款需有协议和往来记录。
7. **股东借款**：股东向公司借款需签借款协议，约定利息/期限，避免被认定为分红或抽逃出资。
8. **税务口径**：本方案按“纯分红”设计；如以后想降低税负，可由税务师测算“工资+分红”组合，但需同步修改本规则。

## 十三、可行性评估：这套机制现在能不能跑

> 本节是对现行 v0.4 规则的现实评估，不改变前面的分配规则；如果采纳本节建议，再在下一版升级。

### 13.1 直接结论

作为一份规则文本，它可以；作为明天就能跑的系统，不行。它会在三个地方卡住，而且都不是“家庭扯皮”，是机制问题。

### 13.2 三个硬卡点

| 卡点 | 为什么会卡 | 最小修复 |
| --- | --- | --- |
| 大姐没有工资 | 她全职负责工厂，收入却完全跟利润波动；坏季度可能一分没有。她会有动机把个人开支混进公司、延迟付款、少计成本，把利润做高；也可能觉得干得多拿得少，干脆不干。法律上，全职厂长不签合同、不发工资、不缴社保，本身就有风险；“40% 分红包含经营责任”不能替代劳动报酬。 | 给大姐固定月薪或固定预支，签劳动合同/劳务协议；如果坚持不叫工资，就叫“固定预分”，有记录、年底冲抵分红。 |
| P 和 F 现在算不准 | 库存靠季度估、采购额当成本、设备没有折旧、税费/社保没有按月计提、旧账和新单容易混。P 不准，分红就是拍脑袋；F 不准，分完可能没钱交税/发工资。 | 月度结账、库存盘点、固定资产折旧、税费计提、旧账/新单拆分台账；先跑两个季度“影子分红”，不真分，和实际现金对一对。 |
| 季度节奏和现金流不匹配 | 客户账期、采购现金、旧账部分要转旧侧；季度末可能“有利润、没现金”，或者刚回款就要付下一季采购。按日历季度分，容易在错误的时间把钱分走。 | 第一年半年度分，季度只做报表和影子计算；或者按回款旺季分。分红前留 3–6 个月固定开支 + 下季度税费 + 已定大额投入。 |

### 13.3 结构问题：40/30/20/10 是所有权，不是报酬

- 大姐 40% + 全职劳动，可能低于她的市场工资；
- 二姐 20% 不干活，拿得可能比大姐的工资还多；
- 你 10% + 系统改造，可能低于你的实际投入；
- 父母 30% 退休，分红随年景波动，旧账清完后现金流会紧。

解决方式不是改比例，而是**把“所有权”和“报酬”分开**：大姐拿工资/管理奖金 + 40% 分红；你拿项目费/系统预算 + 10% 分红；父母拿 30% 分红 + 旧账回款现金流；二姐拿 20% 分红。这样每个人的“劳动”和“资本”各算各的，比例反而更稳。

### 13.4 最小可行启动版本

1. **先给大姐一个固定月薪/固定预支**，哪怕不高；如果坚持不叫工资，就叫“固定预分”，有记录、年底冲抵分红。
2. **父母先用旧账回款（两本账拆分）做季度现金流**；旧账清完后，再评估 30% 分红够不够。
3. **把账做实**：月度结账、库存盘点、固定资产折旧、税费计提、旧账/新单拆分台账和转交流程。
4. **跑两个季度“影子分红”**，不真分；验证 P/F 的误差。
5. **第三季度开始半年度/季度分红**；公式不变，第一年比例 50%，留足储备。
6. **一页纸规则 + 股东签字**；不是防人，是让每次分红不用重新谈判。

### 13.5 启动条件清单

- [ ] 干净主体/股权登记完成，或明确新公司设立时间表；
- [ ] 股东协议/一页纸规则签字；
- [ ] 大姐固定收入方案确定（工资或固定预分）；
- [ ] 父母旧账现金流方案确定（两本账拆分比例）；
- [ ] 月度结账/季度报表能按时出；
- [ ] 库存盘点、固定资产折旧、税费计提、旧账/新单拆分台账和转交流程已落地；
- [ ] 两个季度影子分红完成，P/F 误差可接受；
- [ ] 分红个税/股东会决议流程明确；
- [ ] 父母 30% 股权不存在被冻结/执行的法律障碍（父亲债务问题处理完毕或已隔离）。

### 13.6 一句话

**公式不是最难的部分；最难的是让干活的人有稳定收入，让数字可信。** 这两件事不解决，季度分红撑不过两个季度，最后一定回到“谁管钱谁说了算”的老路。

> 评估结论：现行 v0.4 适合作为目标规则；在完成 13.5 的启动条件前，建议只做“影子分红”，不实际分配。若采纳 13.4 第 1 条，在下一版把“大姐固定预分”写入一页纸规则第 2 条。
